## 命中 · 与闪避对冲的双向词条 + 怪物隐藏面板（2026-11-20 第四轮）

**用户原话**：「我觉得应该有一个和闪避对应的词条，不然闪避太超标了」；追问后定「双向命中」+「小怪/精英/BOSS 都要有和玩家一样的隐藏面板，按等级来，才不会个别词条一边倒」。

### ② 淬炼不是没触发，是回执被卡吞了（真 bug，覆盖面比预想大）

**定位方法**：真实 nonebot matcher + 真实事件跑探针（`tmp/probe_temper.py`），在 handler 三个点插桩打点，然后**抓调用栈**（`bot.py send <- matcher.finish <- __init__.py:行号`）。第一次实验还有两个假象要排除：① `PYTHONPATH` 里放了 `src/plugins` 会让 `doupo` 与 `src.plugins.doupo` **各加载一份**、造出第二个 Store 单例（一次 handler 用有数据的、一次用空的 → 「你尚未踏入」），生产容器 `sys.path` 没有该目录，是探针的错；② `get_player` 里 `mp` 会被 clamp 到 `mp_max`，探针手算 mp 会漂。

**根因**：`puppet_cmd` handler 结尾**无条件** `card.render_puppet_for()` 出傀儡卡，`cmd_puppet` 返回的文本只在渲染失败时才用 → 子命令回执整条丢弃。玩家发「傀儡 淬炼」，`take_materials` 扣了雷淬石、`p["gold"]` 扣了 800 金，却只收到一张没变化的名录卡。受害者 = 淬炼 / 结阵 / 收服 / 融魂 / 配方（**五个都吞**，第十轮加的几个子命令全中）。

**修法**：`commands.PUPPET_SUBCMDS` + `puppet_is_subcmd(arg)` 作「出声 vs 出图」的**唯一真值**，`cmd_puppet` 的分派前缀必须全部登记（有守门比对源码 `arg.startswith("...")`）；handler 里子命令走 `finish_text` 并 return，只有「看傀儡卡」才出图。
