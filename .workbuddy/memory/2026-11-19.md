## 00:20 全表丹药「承诺 ↔ 实现」普查（用户：检查所有丹药是否存在类似问题，全都处理掉）

**由头**：三纹青灵丹假药修完后，用户要求普查全部丹药 + 修正炼药卡描述。

**结论**：75 枚丹药里，**只有 4 枚是真正按原著承诺兑现的**（三纹/紫心/聚气散/斗灵丹），
其余 50+ 枚的 desc 在承诺本作根本没有的系统：

* **短时增益**（增气散/蓄力丹/龙力丹/皇极丹/噬生丹/速灵风丹）——本作 buff 一律永久；
* **升级成功率**（破宗丹/菩提丹/菩提大还丹/阴阳龙玄丹）——本作升级必成，只有斗帝看机缘；
* **封印 / 寿命 / 假死 / 脱战 / 火毒 / 中毒 / 濒死 / 复活**——全无对应状态机；
* **魔兽化形 / 血脉潜力 / 斗气变异 / 丹雷 / 灵魂值**——无对应玩法；
* 青灵丹「提升实力」、二纹「较低阶形态」——玩家会默认同三纹，实际只加修为。

**处理原则（确立契约）**：
* `desc` = 原著功效（考据，不是承诺）；`impl` = 本作真会发生什么（承诺）。
* 卡面 / 包裹 / 「炼药」文本**只印 impl**；desc 只在文本层标「原著：」对照，
  且仅当配方手写了 impl（即这条与自动口径不同）时才打印。
* 两枚真正该破境的补上了：**聚气散**（斗之气九星必入斗者，第54章）、
  **斗灵丹**（斗王必升一星、该阶限一枚 = 一生一次，第211章）。
* 其余 54 条在 `RECIPE_IMPL_OVERRIDE` 里逐条写实话，形如「全属性 +5（原著为短时，此处永久）」
  「气血 +700（无吞火护体流程）」「修为 +3500（升级必成，无成功率）」。

## 09:40 自动调息 + 爬塔固定难度 + 战斗掉疗伤丹（用户三条要求）

**用户原话**：「给斗气和血量加上自动恢复，还有爬塔每层难度固定，不按玩家战力来，
任何战斗掉落增加补血补斗气丹药」。

### ① 自动调息（`core.regen` + `regen_clock` 表）
* 每 `REGEN_TICK_SEC=180` 秒一 tick：气血 `REGEN_HP_PCT=4%`、斗气 `REGEN_MP_PCT=6%`
  （满血 75 分钟、满蓝 50 分钟）。离线同样累计。
* **时间基准只进 `regen_clock(qq, last_at)` 真实列**，不塞 `players.data`（最高声明）。
  hp/mp 仍写既有存档字段，不重构。
* 三条硬约束（都是踩过的）：只推进**整 tick 秒数**（余数留着，否则永远等不到下一 tick）；
  **满状态照吃时间不攒 tick**（否则挂机满血后掉血要白等一轮）；**首次见到只落基准**
  （老档上线不该瞬间满血）。
* 挂载点唯一：`commands._player`（43 处命令共用），失败只 `_warn` 不拦命令。
* 面板末行：「🌿 调息 本次 气血+X、斗气+Y／每 3 分钟 气血+652、斗气+396（离线同样累计）」。
* ⚠️ 恢复量放模块级 `_LAST_REGEN` 旁路缓存，**绝不能挂 p["_regen"]**——p 是 store 活字典，
  临时字段会被 `put_player` 序列化进存档。

### ② 爬塔每层难度固定

  第30层=59、第52层=103（`REF_LV_CAP` 封顶），封顶后靠 `floor_difficulty` 二次增长。

  `monster_scaled(tower_ref_player(ref_lv), species)` 取代 `monster_scaled(fp, ...)`。
* `tower_data.affixes_for(n, rng=None)`：rng 缺省时按层号定种子 → 同层同词缀。
