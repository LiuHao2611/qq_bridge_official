# 傀儡：配方表 · 面板表 · 为什么伤害只有 0.5%

> 2026-11-20 · 用户反馈「我这傀儡伤害这么低啊，用啥炼制的？我需要所有的配方和对应傀儡表」
> 数据来源：`data/doupo/{doupo,puppet_data}.sqlite` 只读副本 + `core.fight()` 真打 + `docker logs`
> 生成器：`tmp/pup_tables.py` / `tmp/pup_real.py` / `tmp/pup_temper.py`

---

## 0. 一句话结论

**只有一份配方，所有傀儡造出来数值完全一样** —— 「用啥炼制」目前是个假选择：
`cmd_craft_puppet` 把魔核阶、灵魂强度、金属档次、炼制之火**全部写死**，
材料只决定卡面印什么字，不参与伤害公式。

而伤害低是三层叠加：① 档位基值是**绝对常数**（120/900/4200），玩家力量却按境界平方级涨到 2 万；
② 三档里最高档减伤后单击也只有怪血的 0.67%；③ 傀儡**只在傀儡遗迹里出场**，
普通遭遇战 / 爬塔 / 周本 / PVP 根本不带它。

## 1. 你的那具是怎么炼出来的

```

      metal=暗金玄铁(2)  fire_tier=7  purity=0  awakened=0  origin=self
```

炼制时扣的材料（`cmd_craft_puppet` 里的硬编码 cost）：

| 材料 | 数量 | 来源 |
|---|---|---|
| 天妖傀竹简 | 门槛（不扣，习得后常驻） | 傀儡遗迹第 3 段「虚空雷池」 |
| 强者躯体 | 1 | 傀儡遗迹第 1 段「魔炎谷库房」 |

| 无主灵魂 | 1 | 傀儡遗迹第 2 段「天墓·能量之层」 |
| 火属性魔核 | 1 | 傀儡遗迹第 2 段 |
| 雷淬石 | 0（留给雷淬，但见 §6.2：实际也不扣） | 傀儡遗迹第 3 段 |

同一份代码里写死的造物参数（**这是关键**）：

```python
# commands.py:2652-2657
puppet = pc.make_puppet(p, body,
    {"core_tier": 7, "core_attr": "火"},
    {"soul_source": "无主灵魂", "soul_strength": 900, "mind_stripped": True},
    {"metal_name": "暗金玄铁", "metal_grade": 2},
    {"fire_tier": 7, "fire_attr": "火"})
```

`make_puppet` 里 `tier = first_craft_tier()` 恒返回 0 —— 注释写着「首炼恒人级铜，与材料档次无关，
材料只定成长上限」，但**代码里没有任何一处读 material 定上限**。

## 4. 面板表（真跑 `puppet_core.puppet_attack`）

### 4.1 公式

```
每回合肉身伤害 = (档位基值 + 魔核阶 × 40 + 灵魂强度 × 0.15) × 0.42
结阵增益       = × (1 + 0.15 × (同场傀儡数 − 1))
傀儡异火       = × max(1.0, 1 + Σ(火加成 × 持有等级))
实战单击       = 上式 × mitigation(怪防御)
```

### 4.2 三档面板（魔核 7 阶 / 灵魂 900 为标准造物）

| 档 | 名称 | 基值 | 魔核7阶 | 灵魂900 | 小计 | ×0.42 | 结阵2人 | 结阵3人 | 升档条件 |
|---|---|---|---|---|---|---|---|---|---|
| 0 | 人级傀儡（铜） | 120 | 280 | 135 | 535 | **224.7** | 258.4 | 292.1 | 首炼恒此档 |
| 1 | 地级傀儡（银） | 900 | 280 | 135 | 1315 | **552.3** | 635.1 | 718.0 | purity ≥ 0（见 §6.1） |
| 2 | 天级傀儡（金） | 4200 | 280 | 135 | 4615 | **1938.3** | 2229.0 | 2519.8 | purity ≥ 60 |

### 4.3 傀儡异火加成（只认 4 朵 B 线火，你一朵都没有）

## 5. 实测：低到什么程度（lv81 真打一场）

### 5.1 你的存档实战（`core.fight`，seed=11）

```

傀儡击 7 次，每次 41 点 → 累计 287
玩家击 12 次，样本 [3780, 5670, 29768, 8930, 3780, 3780]
傀儡累计伤害 / 怪血 = 0.54%
```

### 5.2 三档对比（减伤后真实单击）

| 档 | raw | 实战单击 | 占怪血（52832） | 8 回合总贡献 |
|---|---|---|---|---|

## 6. 顺带挖出的四个结构问题（都不是数值不对，是接线错了）

### 6.1 升档门槛表索引错位：第一次雷淬直接跳地级

```python
PUPPET_TIER_UP_PURITY = (0, 60, 100)   # 注释说「0→1 需 60；1→2 需 100」
...
if purity >= cfg.PUPPET_TIER_UP_PURITY[tier]:   # 读的是「当前档」，不是「目标档」
```

tier=0 时门槛取到 `[0] = 0` → 雷淬一次（purity 12）就 ≥ 0 → 立刻升地级。
实测曲线：

```
第1次 purity=12%  tier=1 地级    ← 本该 5 次
第2次 purity=24%  tier=1
第3次 purity=36%  tier=1
第4次 purity=48%  tier=1
第5次 purity=60%  tier=2 天级 capped ← 本该 9 次
累计 5 次 × 800 = 4000 金就封顶
```

### 6.2 「雷淬石」永不消耗

`_cmd_puppet_temper` 只扣金币 800，**没有任何材料扣减**。
你包里那 2 颗雷淬石从掉落到天级封顶一次都用不上。

### 6.3 材料档次 / 炼制之火对伤害零影响

`puppet_attack` 只读 `tier` / `core_tier` / `soul_strength`。
`metal_grade`、`fire_tier`、`body_star`、`body_realm` 全程**只出现在卡面文案**里。
暗金玄铁和普通铁炼出来一模一样。

### 6.4 傀儡只在傀儡遗迹出场

全仓库只有一处 `fight(..., puppet=...)`：`commands.py:2699`（傀儡遗迹）。
`cmd_fight` 走的是 `core.encounter(p, locked=locked)` —— 不带傀儡；
爬塔、周本、PVP 同样不带。所以傀儡日常打怪完全不出场。

### 6.5 附带：「十具同阶连成循环可短暂进化」是纯文案

`_cmd_puppet_formation` 只打印这句话，代码里没有任何「循环 / 进化」实现。
结阵实际只有 `+15% × (傀儡数−1)`，且**只有 1 具真正出手**（`fight` 收到的是单个 `pu`）。

## 7. 修法待拍板

| 方案 | 做法 | 代价 |
|---|---|---|
| **A（推荐）** | 档位基值改成**跟玩家力量锚定**（人级 25% / 地级 60% / 天级 100% 本体普攻），把 E09 的「天级≈斗尊」真正兑现 | 需要重测九星突破/爬塔胜率（傀儡会进反解） |
| B | 只修 6.1/6.2/6.4 三个接线 bug，数值仍绝对常数 | 修完天级仍只有怪血 1.33%，治不了本 |
| C | 让 `metal_grade` / `fire_tier` 进公式（3.5 / 2.5 倍系数） | 回答「用啥炼制」这个诉求，但绝对值仍会随等级衰减 |
| D | 傀儡进普通遭遇战 / 爬塔（PvE 全场景常驻） | 直接改变 TTK 设计值，怪物反解要全部重标定 |

**建议 A + C + 修 6.1/6.2**：先让「材料有区别 + 数值跟等级走」，
再单独决定要不要让傀儡进日常战斗（D 影响面最大，建议最后做）。
