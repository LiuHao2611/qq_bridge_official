# 傀儡战力锚定 + 五处战斗接入（2026-11-20 第二轮）

> 用户原话（本轮唯一指令）：
> **「其他战斗都要带上，不然炼制傀儡没有意义，还有我这个傀儡战力低的离谱，正常吗」**
>
> 拆成两件：A. 五处战斗全部带出战傀儡；B. 傀儡战力低得离谱是否正常 → 先诊断再修。

---

## 1. 诊断：低得离谱，属实，不是错觉

真跑 `tmp/probe_pup_anchor.py`（只读，不手算）：

| 项 | 旧口径实测值 | 说明 |
|---|---|---|
| lv81 玩家每回合期望输出 | **36344** | `damage_schedule` 平均 |
| 旧人级傀儡输出 | **224.7** | 绝对常数 `PUPPET_TIER_BASE[0]=120` × 系数 |
| 傀儡 / 玩家输出 | **0.62%** | 带了等于没带 |
| 傀儡一击 / 同阶怪血 | **0.08%** | 怪血 33182 |

根因一句话：**`PUPPET_TIER_BASE=(120,900,4200)` 是绝对常数，不跟等级走。**
玩家从 lv20 到 lv102 输出涨了 50 倍，傀儡始终 120/900/4200。

叠加第二个根因（用户说「没意义」的数学解释）：`monster_scaled` 旧版把
`puppet_bonus` **全额**计入怪血反解。于是「多一个打手」与「怪血同步变厚」在
数学上完全对消 —— 回合数、胜率、承伤全部不变。**即使把傀儡数值修大，只要
折扣是 1.0，带傀儡依然零收益。** 这一点由注入反证证明（见 §5）。

## 2. 新口径：锚定玩家自己的输出

```
傀儡每回合原始伤害 = 该玩家平均每回合期望输出 × PUPPET_TIER_RATIO[tier] × 材料系数
```

| 常数 | 值 | 含义 |
|---|---|---|
| `PUPPET_TIER_RATIO` | `(0.15, 0.30, 0.50)` | 人级 = 15% 个自己 / 地级 30% / 天级 50% |
| `PUPPET_REF_LV` | `(35, 65, 80)` | 没有玩家上下文时的标尺等级，走 `core.tower_ref_player`（与爬塔同一套标尺，不另造假玩家） |
| `PUPPET_ENEMY_COMP` | `0.55` | 怪血只按傀儡贡献的 55% 变厚 → 带傀儡净赚 45% |
| `PUPPET_FORMATION_MAX` | `3` | 结阵最多算 3 具（堵刷分后门，见 §4） |

材料系数（同一档**之内**的差异，基准 = core7 / soul900 / metal2 / fire7 = 1.00）：

```
1 + (core_tier − 7) × 0.02          # 魔核每高 1 阶 +2%
  + (soul − 900) × 0.00006          # 灵魂每高 1 点 +0.006%
  + (metal_grade − 2) × 0.05        # 金属每高 1 级 +5%
  + (fire_tier − 7) × 0.04          # 火每高 1 档 +4%
```

⚠️ 基准点刻意取**旧档值**（grade2 / fire7）：老存档库列缺 `metal_grade`/`fire_tier`
或为 0 时回落基准，材料倍率**恰为 1.0**，绝不吃惩罚。

### 修后量级

| lv | 玩家回合输出 | 人级铜 | 地级银 | 天级金 | 天级占比 |
|---|---|---|---|---|---|
| 10 | 1553 | 207 | 501 | 1017 | 65.5% |
| 35 | 6094 | 814 | 1967 | 3992 | 65.5% |
| 65 | 28210 | 3766 | 9106 | 18478 | 65.5% |
| 81 | 36344 | 4852 | 11732 | 23805 | 65.5% |
| 105 | 76622 | 10229 | 24734 | 50187 | 65.5% |

占比恒定（因为锚定的是玩家输出的比例），绝对值随等级增长 —— 这正是「跟等级走」。

lv81 实战：人级一击打掉怪血 **2.97%**、地级 **7.17%**、天级 **14.56%**（旧版 0.08%）。

## 3. 五处战斗接入

**纪律：怪血反解用的 `p` 与实战 `fight(puppet=...)` 用的 `p` 必须是同一个，
且都走 `puppet_core.puppet_attack` / `puppet_expected_damage` 唯一函数。**

| 战斗 | 入口 | 怪血锚 | 实战傀儡锚 | 备注 |
|---|---|---|---|---|
| 野外遭遇 | `encounter` | 真人 `p` | 真人 `p` | 整场算一次 `_pu_bonus`，逐敌反解 |
| 爬塔 | `tower_floor` | **标尺 `tower_ref_player(ref_lv)`** | 真人 `fp` | 同层永远同一只怪，不能随打它的人变厚 |
| 周副本 | `weekly_floor` | **周一快照画像** | 真人 `fp` | 当周难度锁定，当周新炼的傀儡不使怪变厚 |
| 九星突破 | `nine_star_breakthrough` | 触发瞬间快照 `snap` | 真人 `p` | 突破是唯一境界关口，不带傀儡等于白炼 |
| PVP | `duel` | 无反解 | 双方各自 | 无怪血，傀儡是净增输出；**双方对称** |

命令层统一入口 `commands._puppet_ctx(qq, p)` → `(puppet, formation_n, flame_mult)`，
无傀儡返回 `(None, 0, 1.0)`（与不传参逐字节等价）。七处调用点全部透传：

- `cmd_fight`（野外）、`cmd_tower`（爬塔）、`cmd_weekly`（周本）、
  `cmd_break`（九星突破）、`cmd_rob`（掠夺，双方）、
  `cmd_duel_accept`（切磋，双方）、`cmd_ruin`（傀儡遗迹）

`flame_mult` 与 B 线傀儡异火**同源**：一个倍率同时喂怪血反解与实战傀儡击，
漏传就是「卡面写的加成」与「实际打出来的伤害」两张皮。

### PVP 对称性

`duel(p, vic, ..., puppet=, vic_puppet=)`。被挑战方虽是离线对象，傀儡表仍可查，
所以双方都按自己的存档带 —— 谁炼了谁受益，不是单向碾压。被控则该轮傀儡同罚。

## 4. 结阵封顶（顺手堵的后门）

`formation_count()` 数的是玩家**拥有的全部**傀儡，每具 +15%，原本无上限。
人级材料极便宜（精铁 + 火属性魔核 + 无主灵魂），凑 5 具就能白拿 +60%，
叠上本轮新口径会变成天级 `65.5% × 1.6 = 104%` —— 傀儡比人还强。

现封顶 3 具（`PUPPET_FORMATION_MAX=3`），且封顶放在 `formation_count` 里
而不是只放公式里：命令层/卡面报的「结阵 N 具」与真正吃到的加成必须是同一个数。

| 具数 | 1 | 2 | 3 | 5 | 8 |
|---|---|---|---|---|---|
| 人级 | 13.3% | 15.4% | 17.4% | 17.4% | 17.4% |
| 地级 | 32.3% | 37.1% | 42.0% | 42.0% | 42.0% |
| 天级 | 65.5% | 75.3% | 85.2% | 85.2% | 85.2% |

## 5. 验证证据

### 5.1 「净赚」由折扣唯一决定（含反证）

同种子 8 组对照，靶 = 同阶怪：

| lv | comp | 怪血空手 → 带傀 | 回合（不带） | 回合（带） |
|---|---|---|---|---|
| 35 | **0.55** | 15236 → 20725 (+36%) | 4,5,4,5,5,5,5,6 | **4,4,4,4,4,4,4,4** |
| 35 | 1.00 | 15236 → 25215 (+66%) | 同上 | **4,5,4,5,5,5,5,5**（≈对消） |
| 81 | **0.55** | 33182 → 45136 (+36%) | 4,5,5,5,4,4,5,5 | **4,4,4,4,4,4,4,4** |
| 81 | 1.00 | 33182 → 54916 (+66%) | 同上 | **4,5,5,5,5,5,5,5**（≈对消） |

**这是「炼傀儡没意义」的完整数学解释**，也是 `PUPPET_ENEMY_COMP` 存在的理由。

### 5.2 守门测试 `tests/test_doupo_puppet_anchor.py`（57 条，全绿）

覆盖：七处签名收 `puppet` / 命令层 AST 断言每个 `core.*` 战斗调用都带 `puppet=` /
锚定随等级 / lv81 天级 ≥40% 且 <100% / 人级 ≥8% / 档位梯度 / 材料系数 / 老档恰 1.0 /
结阵封顶 / 净赚 / 全额对消反证 / `PUPPET_ENEMY_COMP` 实际值区间 / 不带傀儡零变化 /
PVP 双方对称与日志归属 / 五处战斗真跑日志必有「傀儡击」/ 塔锚标尺源码红线。

⚠️ 塔与周本的用例必须**打深层 / 传真实画像**：第 1 层怪血只有 4000~8000，
lv60 玩家先手就秒了，傀儡根本没机会出手 —— 那样会写出假红/假绿的用例。

## 6. 已知边界（不是 bug，是设计选择）

1. **塔与周本的怪血不随「打它的人」变**。带一具同档更强的傀儡，收益全额落袋；
   带一具更弱的，收益打折。这是「同层同一只怪 / 当周同一难度」的必然结果。
2. **PVP 带傀儡 = 净增输出**，没有怪血可以变厚。有傀儡的人打没傀儡的人是碾压，
   但这是「炼傀儡要有用」的直接后果；对称口径保证被挑战方也有同样的机会。
3. **`test_battle_encounter.py` 在本环境不可跑**（pytest 风格，镜像与宿主机都没有
   pytest），属既有基线，与本轮无关。
