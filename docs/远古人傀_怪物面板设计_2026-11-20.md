## 1. 原著给了什么（每条挂原文）

### 1.1 制造方式与定位

> 「这是**远古人傀**，以特殊手段将强者的灵魂抽出人体，然后封印于傀儡躯体内，
> 如此这般制造而出的傀儡，**不仅拥有着神智，而且还能施展斗技**，远比寻常傀儡棘手。」
>
> 「这些人傀已是那位**斗圣强者的最后防卫**……经历无数岁月，依旧一丝不苟的
> 执行着他所布置而下的命令。」
>
> 「为了制造这些傀儡，他至少便是**杀了十几名的斗尊强者**？」

- 每个材料是一名**斗尊强者**的灵魂 + 躯壳；十具 ≈ 十几条斗尊人命。
- 定位是**遗迹守卫**，不是野外怪：只在「主人下过的命令」范围内活动。

### 1.2 战力档

> 「这群傀儡实力**全都在斗尊层次**，同时出手，声势极度骇人……
> 除了一些大势力之外，根本无人有与它们抗衡的实力，往往都是
> **交手两三回合，便是会这些傀儡生生撕裂**。」

- 单具 = 斗尊；群体出手时普通强者两三回合就被撕碎。
- 对照本作等级轴：斗尊 ≈ lv73~81，斗尊巅峰 ≈ lv90（见 `cfg.REALM_TABLE`）。

### 1.3 攻击特点（玩家实际会挨的打）

> 「前方不远处的十几道身影，猛然间爆裂成一团血雾，那血雾之中，
> **一道灰影快若闪电般的掠出，一杆鲜血淋漓的长枪，带着凌厉无匹的劲风，
> 对着萧炎等人暴刺而来**。」

归纳成三条：

| 特点 | 原文依据 | 战斗语义 |
|---|---|---|
| **peed 突进** | 「灰影快若闪电般掠出」 | 先手近身，玩家反应窗口短 |
| **长枪暴刺** | 「一杆鲜血淋漓的长枪……暴刺而来」 | 单体高伤突刺（burst 型） |
| **会施斗技** | 「不仅拥有着神智，而且还能施展斗技」 | 不是纯平A，有技能释放 |

⚠️ **原著从头到尾没有给出任何一招斗技的名字**。「长枪」是它出现的唯一武器，
「斗技」只是泛称。本作若要给技能起名，只能用描述性名（如「血枪突刺」），
并在卡面避免让人误以为是原著专名。

### 1.4 防御特点

> 「这些傀儡的身体表面上，似乎被缠绕上了**一层层灰白色的奇异布条**，
> 这些布条闪烁着异样的光泽，**柔软的同时，又具备着相当之强的防御力**，
> 即便是**斗宗强者的全力一击，都是无法震断这种奇异布条**。」

- 防御类型是**「柔而不断」**：不是硬甲反弹，而是斗宗全力一击都震不断。
- 与天妖傀的「身若金铁、屏蔽痛觉」是两种不同质感：天妖傀靠金铁，人傀靠布条。
- 原著只给定性描述，**没有给减伤比例**，本作要用数值落地必须自己定。

### 1.5 行为逻辑与弱点

> 「这些傀儡一苏醒，便是**对最近的人下杀手**……已经将他们也是**纳入了攻击范围**之中。」
>
> 「小医仙：没事，我将那人傀**引到别处去了**，这些东西**虽有杀伐之意，但却并不具备理智**。」
>
> 「在傀儡种植印记之处，他察觉到了一股**无比强悍的烙印**，这种烙印，绝对是那位
> **斗圣强者亲自所下**……『无法控制，印记太强，现在的我，无法将之抹除。』」
>
> 「有着好几具被众多强者**围攻震成了粉末**，但所遗留而下的，依旧还是有着六具之多。」

关键点——**「有神智」与「无理智」不矛盾**：

* **有神智** = 能自主施斗技、能一丝不苟执行守卫命令；
* **无理智** = 不能沟通、不能劝诱、不能收服（印记是斗圣下的）。

可落地的弱点只有三条：

1. **可被诱导**：小医仙把它引到别处 → 目标选择可被操控，不是无脑锁定最近；
2. **可被围杀**：十几具里好几具被围攻震碎 → 非无敌，群殴能拆；
3. **不可收服**：印记太强抹不掉 → 不进 `claim_puppet` 池、不掉傀儡材料。

⚠️ 别编造它「免疫控制/免疫沉默」——原著只说不能沟通与收服，没说不眩晕不中毒。

### 1.6 别混淆：同一章的「斗圣骨骸」不是人傀

以下三招属于**斗圣骨骸（生前一丝灵魂残印）**，原文主语都是骨骸：

> 「连摘星老鬼这等实力，都经受不住这具**斗圣骨骸的一记音波咆哮**。」
> 「骷髅的速度极为恐怖……面前的空间便是被其**生生撕裂**。」
> 「看似脆弱的骨骼，在此刻却是**比精钢还要坚硬**。」

做面板时不能把这几招安到人傀身上——两者同场、不同单位。

## 3. 面板草案（本作设计，可评审）

> 以下全部是**本作实现建议**，不是原著设定。

### 3.1 定位与挂接

| 字段 | 建议值 | 理由 |
|---|---|---|
| 放置位置 | 傀儡遗迹新增一段「斗圣遗迹·主殿」或现有「圣地残殿」精英变体 | 原文场景就是斗圣遗迹守卫 |
| 等级 | lv 78~85（斗尊档），群体 3 具 | 单具斗尊；本作 encounter 上限 5，3 具留出梯度 |
| kind | `斗圣遗迹·elite` | 走现有「名字含精英/含 elite → 面板 ×1.20」通道 |
| is_boss | False | 原文是群体守卫，不是单 BOSS |
| 收服 | **禁止**（不进 `claim_puppet`，不掉傀儡材料） | 印记抹不掉 |

### 3.2 技能组（沿用现有 effect，不自造轮子）

现有怪物技能结构：`{"name", "chance", "effect", "mult"}`，
`effect` 已支持 `burst / drain / poison`（见 `config.MONSTERS` 与 `BREAK_BOSSES`）。

| 槽 | 建议名 | effect | mult | chance | 对应原文 |
|---|---|---|---|---|---|
| 主 | 血枪突刺 | `burst` | 1.5~1.6 | 0.22~0.26 | 「鲜血淋漓的长枪……暴刺而来」 |
| 副（可选） | 布条绞杀 | `drain` | 0.08~0.10 | 0.18~0.20 | 「柔软却震不断」→ 缠住吸取 |

- 名字是**描述性设计名**，不是原著专名；卡面来源标记按本作技能处理。
- 技能命中时才挂效果，沿用 `skill_effects.on_hit`，不动 `fight()` 的伤害反解链路。

### 3.3 防御与隐panel

- 防御：本作用 `def` 表达「布条柔而不断」，建议在 `monster_scaled` 给该 kind 加一个
  `def` 系数（本作设计），**不改 `MITIGATION_W`、不改 hp/atk 反解**——
  这是「难度只由等级/层号决定」红线的延伸，防御表现可以变，胜负曲线不能因此漂移。
- 命中/闪避/暴击：直接走已上线的 `monster_panel(lv, kind, is_boss)`，
  人傀不该有专属隐藏面板常量。

### 3.4 行为（最贴原著的一条）

「一苏醒便对最近的人下杀手」+「可被引到别处」→ 建议本作 AI：

```
没被诱导：锁定我方傀儡优先（它是护卫 → 先撕护卫，符合「对最近的人下杀手」）
被诱导后：目标转向诱导源，持续 N 回合
不可沟通：话术/收服类口令一律无效（不是「免疫控制」）
```

⚠️ 这条要动 `fight()` 的目标选择，风险中等，必须与「单场消耗、跨场满血」的护甲口径一起回归。

### 3.5 门禁方案（若拍板实施）

| 守门 | 断言 |
|---|---|
| 原著绑定 | 每条技能名/出处能定位到原文；「不可收服」有 `claim_puppet` 拒绝分支 |
| 反解零回归 | 面板变化不改 hp/atk；既有 `test_battle_review` 逐招快照零回归 |
| 行为 | 同种子：无诱导打护卫 / 有诱导转向；不可收服真拒绝 |
| 变异工具 | 撤诱导 / 开放收服 / 技能名挂原著专名 / 布条写死减伤 → 全红 |

参考现有守门规模：`test_doupo_puppet_guard.py`、`test_battle_review.py`、
`tools/mutate_hit_rate.py`。

## 4. 落地风险与未定项

1. **最大风险是「招式名」**：原著零命名。任何具体招式名都是本作设计，
   必须在本作文案体系里诚实呈现（内部文档可标注，玩家可见处不写「原著中有此招」）。
2. **布条防御的数值**没有原著锚点，拍脑袋定 1.2× 还是 1.5× 都得靠 `_balance.py` 验证。
3. **诱导机制**要动 `fight()` 目标选择，是这份面板里唯一的中风险项；
   其余都是配置 + 既有 effect 组合。
4. 是否进「傀儡遗迹」还是另开「斗圣遗迹」入口，属于玩法位置决策，等拍板。
