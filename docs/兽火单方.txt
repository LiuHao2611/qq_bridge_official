紫火丹（原著已有，作为基准）

兽火：紫火（紫晶翼狮王）

丹方：一滴紫晶源 + 一滴吞天蟒唾液 + 火属性药材

功效：重新调用紫火，用于融合佛怒火莲

乾蓝丹

兽火：乾蓝水炎（惊涛龙兽）

丹方：惊涛龙兽精血一滴 + 寒霜花霖三株 + 二阶水魔核一枚 + 蓝晶草两株

功效：服后双手可凝出乾蓝水炎，火焰温和绵长，适合在炼制水属性丹药时临时替代兽火，也可用于压制火毒

幻金火丹

兽火：幻金火（幻火蝎龙兽）

丹方：幻火蝎龙兽蜕壳粉末一份 + 金线蕨两株 + 三阶火魔核一枚 + 赤阳花一朵

功效：释放金黄色幻金火，火焰带有轻微幻术干扰效果，炼药时可提升对药材杂质的剥离精度

海魔丹

兽火：海魔炎（海魔兽）

丹方：海魔兽涎液一滴 + 深海藻三株 + 四阶水魔核一枚 + 蓝灵果一枚

功效：释放深蓝色海魔炎，火焰韧性极强，适合长时间炼药，也可作为五轮离火法的备用火种

天阴丹

兽火：天阴魔火（天阴三头狮）

丹方：天阴三头狮鬃毛灰烬一份 + 阴骨藤两株 + 五阶暗属性魔核一枚 + 冥花一朵

功效：释放淡黑色天阴魔火，火焰附带侵蚀效果，可用于破解对手斗气护甲，炼药时需谨慎控制以免侵蚀药材

血妖丹

兽火：血妖焰火（近千头火属性魔兽血液融合）

丹方：百头火属性魔兽血液凝晶一份 + 血莲精一株 + 六阶火魔核一枚 + 妖血草三株

功效：释放血红色兽火，威力接近低阶异火，适合高阶炼药师在缺乏异火时作为替代火种

桃花丹

兽火：桃花火（奎木兽）

丹方：奎木兽木心粉末一份 + 桃花瓣七片 + 二阶木魔核一枚 + 青灵草两株

功效：释放温和的桃花色火焰，火焰温度不高但极为稳定，适合新手炼药师练习控火，也可用于温养药材

天寒丹

兽火：天寒火（天骨蟒）

丹方：天骨蟒骨髓一滴 + 寒冰草三株 + 三阶水魔核一枚 + 骨灵花一朵

功效：释放外冷内热的寒性火焰，可用于炼制需要“冷火”处理的特殊药材，也能辅助压制体内火毒
