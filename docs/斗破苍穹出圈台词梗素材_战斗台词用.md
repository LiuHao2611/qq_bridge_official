## 3. 落地边界 `[推断 / 注意]`

1. **只用短句，别写「本梗出自……」** —— 你之前反复纠正过的沉浸红线。
2. **本次已按你的要求筛除人物指称**：人名、角色绰号、称呼一律不进素材表；只保留可复用的梗句本身。跨圈流传那批（含其他游戏角色名）整段删除。
3. **区分「玩梗」和「黑作品」**：`斗气化马`、`魔改`、`羊驼建模` 是拿剧版/动画开涮的，写进自己游戏的战斗回包会显得在嘲讽玩家喜欢的东西。这批只放菜单彩蛋或节日活动。
4. **带阵营口吻的三条最安全**：`桀桀桀` 归反派势力，`猖狂` 归高傲反派，`侥幸罢了` 归玩家胜利回包。三者都不需要解释，也不点名任何人。
5. **长句克制**：`莫欺少年穷`、`这一击竟撕裂了虚空` 只放在关键回合（越阶、Boss 终结），不要每场都贴。
6. **「恐怖如斯」是双关**：既能赞也能嘲。放玩家身上是自嘲，放敌人身上是轻蔑，靠上下文决定，不要在同一回合两边都用。
7. 本次**不做原著考据引文验证**——按你的要求只看全网传播口径；如果以后要把某句正式写进产品文案，再按项目守门补来源核验。
