# 二次穷举：药方考据修订（2026-11-16）

用户指出「不可能只有这几个丹药有配药」。复查成立——第一版只给 10 枚写了 `need`，
属于漏检，不是原文没有。全文重扫后增加到 **20 枚有药方、36 枚逐枚留无方审计**。

## 上一轮为什么漏

1. **前置过滤太窄**：只搜「材料 / 配方 / 需要」且要求与丹名同句。原著大量药方是
   「先说丹名、隔几句才列药材」，例如第五十四章聚气散、第九章筑基灵液，整段被跳过。
2. **上下文窗口太小**：只看 300 字。护脉丹 / 冰心丹的药材散在第一百五十章与
   第一百五十六章两段，必须 1000+ 字窗口才捞得到。
3. **被转载版笔误带偏**：第900章章节标题是「炼制天魂融血丹」，正文却冒出一句
   「天火融雪丹的炼制之法」。第一版把这个只出现 1 次的词当成独立丹药，并把
   天魂融血丹的 77 种材料方错安在它头上。本版已纠正：药方归天魂融血丹，
   天火融雪丹标存疑、不给药方。

扫法：对 1608 章 / 4,977,536 字的索引先做**无前置过滤**的全命中导出
（每味丹每次出现都留 1100 字窗口），再按药方线索密度排序人工逐条判读；
另做一次全局「炼制材料 / 所需材料 / 药方 / 准备…」句式扫描交叉验证。
过程产物在 `tmp/scan_recipes_exhaustive.py`、`tmp/recipes_candidates.py`、
`tmp/global_recipe_patterns.py`（不入库）。

## 仍无药方的 36 枚

逐枚判定依据在 `recipe_evidence.py::NO_RECIPE_AUDIT`。分三类：
仅述功效/使用（如增气散、龟息丹、返命丹）；原文说有药方但没列药材（如破厄丹、
噬生丹、火菩丹、素心丹）；只点名部分材料不成方（回气丹只知第五种「回灵赤果」）。
另「冰灵护喉液」第433章有完整方但是辅助药品，在 `OUT_OF_SCOPE` 留档，不并入丹药池。

## 防重犯门禁

`tests/test_doupo_recipe_evidence.py` 六条：need 必须有原文引文、引文字样必须自洽、
`need={}` 必须有审计记录且不能同时有证据、药材必须在宝库里、有药方数不得回退到 20 以下、
第900章归属不得再错。已用本次真实错误回退验证：把聚气散改回 `need={}` → 门禁报错；
给它填一个不存在的药材 → 门禁报错。
