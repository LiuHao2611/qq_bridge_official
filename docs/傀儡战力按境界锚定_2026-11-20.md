# 傀儡战力按「躯体境界」锚定（2026-11-20 第三轮）

> 用户原话：**「我觉得傀儡应该有原著中说的，有对应斗宗或者斗尊级别的战力」**
>
> 这是对第二轮「玩家输出 × 0.15/0.30/0.50」口径的**实质修正**：傀儡战力应当锚
> **材料境界**，而不是锚玩家输出的一个百分比。
>
> ⚠️ 本文取代 `docs/傀儡战力锚定与五处战斗接入_2026-11-20.md` §2。
> 那两个常量（`PUPPET_TIER_RATIO` / `PUPPET_REF_LV`）**已删除**，别再引回来。

---

## 0. 一句话结论

**战力由躯体境界决定，档位只负责「不抢风头」的封顶。**

```
傀儡每回合原始伤害 = min(躯体境界标尺输出, 玩家每回合输出 × PUPPET_ATK_CAP[档]) × 材料系数
```

- 第一项给「斗宗 / 斗尊级战力」，来自**躯体**（原著第 757 处的折算规则）；
- 第二项是安全阀：玩家比傀儡弱时往下压，防止一具高级傀儡碾穿全场；
- 两者取小 → 同时满足用户两条红线（「要有斗宗级战力」+「不能抢玩家风头」）。

| 第 971 处·大风暴 | 「这具天妖傀……**约莫四星斗尊**左右的实力，后来经过虚空雷池强化……已能够与**六星斗尊**相媲美，如今再经过阵法吸收十具……它的实力，无疑是**瞬间超越了萧炎**」 | 天级 ≈ 六星斗尊；且「超越」是**结阵十具**才做到的 → 单具不该越过玩家 |

3 具（`PUPPET_FORMATION_MAX=3`），所以单具封在 95%。

## 2. 为什么「比例口径」必须废掉（三轮演进，别再绕回去）

| 轮次 | 口径 | 实测病症 |
|---|---|---|
| ① 初版 | `PUPPET_TIER_BASE=(120,900,4200)` 绝对常数 | lv81 人级只占玩家输出 **0.2%** —— 用户「低得离谱」 |
| ② 第二轮 | `玩家输出 × (0.15/0.30/0.50)` | 比例有了，但 lv81 人级仅 5.5 千、地级 1.1 万，与原著「地妖傀 = 五星六星斗宗」完全对不上；若改成「同境界满额」，lv20 会到 **1134%**（实测）直接崩 |
| ③ 本轮 | `min(躯体境界标尺, 玩家输出 × CAP) × 材料系数` | 见 §4 实测表：高级玩家身上三档 51%/80%/95%，低等级被 CAP 压住不崩，后期靠北王傀续上 |

第二轮的根本错误：**把「傀儡有多强」挂在了玩家身上**。玩家越强傀儡越强、玩家换套
装备傀儡跟着变强 —— 但原著里傀儡的强度是炼出来那一刻就定死的（第 971 处雷池淬炼
才涨），跟萧炎穿什么无关。

## 3. 配置（唯一真源，`config.py` 傀儡战力段）

| 常量 | 值 | 含义 |
|---|---|---|
| `PUPPET_ATK_CAP` | `(0.55, 0.80, 0.95)` | 三档的「不抢风头」上限（占玩家每回合输出） |
| `PUPPET_BODY_STAR_PENALTY` | `2` | 躯体 n 星 → 战力 n−2 星（第 757 处） |
| `PUPPET_TIER_REALM_LV` | `(55, 68, 73)` | `body_realm` 缺失时的回落：斗皇一星 / 五星斗宗 / 斗尊一星 |
| ~~`PUPPET_TIER_RATIO`~~ | **已删** | 旧「玩家输出百分比」口径 |
| ~~`PUPPET_REF_LV`~~ | **已删** | 已改名 `PUPPET_TIER_REALM_LV`（语义从「标尺等级」变成「该档标准躯体的折算境界」） |

⚠️ **命名坑**：`PUPPET_TIER_CAP` 这个名字**已被占用**（值 `2`，含义是「材料档位封顶
天级」）。本轮第一版误用了同名常量，被文件后面那段静默覆盖成 `2`，`float(cfg.PUPPET_TIER_CAP[tier])`
直接 `TypeError`。所以战力封顶必须叫 `PUPPET_ATK_CAP`。

### 3.1 躯体 → 战力的折算（`puppet_core.puppet_realm_lv`）

```python
idx  = cfg.REALM_NAMES.index(body_realm)          # 斗皇 / 斗宗 / 斗尊 / 斗圣
n    = max(1, min(9, body_star or 1))             # 未标小星按一星
lv   = cfg.realm_lv(idx) + max(0, n - 1 - PENALTY)  # n-2 星
lv   = min(lv, cfg.realm_lv(idx) + 8)             # 封在该境界内，不跨级
```

| 躯体（`PUPPET_BODY_TIERS`） | 折算战力 | 本作等级 |
|---|---|---|
| 强者躯体（斗皇·未标星） | 一星斗皇 | lv55 |
| **斗宗强者之躯（斗宗·7星）** | **五星斗宗** | **lv68** |
| 斗尊强者之躯（斗尊·未标星） | 一星斗尊 | lv73 |
| 北龙王之躯（斗圣·5星） | 三星斗圣 | lv96 |

> 本轮顺手把 `北龙王之躯` 的 star 从 `0` 改成 `5` —— 表注释本来就写着「五星斗圣之躯」，
> 值却是 0，导致北王傀的战力被按「一星斗圣」算。改后它成为 lv94+ 玩家唯一的成长路径。

### 3.2 后期成长路径

普通斗尊躯的天级傀儡封顶在「一星斗尊」，lv95 之后玩家输出反超，占比自然下滑到 73%/61%。
要跟上只能换料：**北龙王之躯（斗圣）→ 三星斗圣**，在 lv95/103 重新回到约 100%（受 CAP 压到 95%）。
这正是第 971 处「雷池淬炼 → 六星斗尊」的同一条设计语言：**换更好的躯体**。

## 5. 卡面口径：标签必须与数字自洽

`puppet_core.puppet_realm_label(puppet, p)`：

- **未被压制** → 标材料境界（「斗尊级」）；
- **被 CAP 压住且跨了大境界** → 标实际发挥 + 「· 受你境界所限」（「斗师级 · 受你境界所限」）；
- **同境界内被压不降档** → 斗尊躯被压到斗尊初段，仍叫「斗尊级」。

反查用 `puppet_effective_lv()` 二分标尺输出曲线（`_round_output_at`），不手算。

⚠️ **文案两坑**：
1. label **不许带括号**。卡面格式是 `肉身攻击 N　{label}（不吃斗气/斗技）`，若 label 自带
   `（受你境界所限）` 就成了 `（斗皇级（受你境界所限），不吃斗气/斗技）` —— 两层中文括号
   （实测真实数据踩到）。用「·」断句，守门 `test_card_shows_realm_label` 逐行查括号数。
2. 标签用**实际发挥**而不是材料境界，否则就是「写着斗宗级、打出来一千七」的假标签。

## 6. 本轮顺手修的两个真 bug

### 6.1 材料系数把「不抢风头」撑破

第一版写的是 `min(境界标尺, 玩家×CAP) × 材料系数`。天级顶配材料的系数是 **1.31**
（core9 +0.04 / soul2400 +0.09 / metal4 +0.10 / fire9 +0.08），于是：

```
min(47097, 3153 × 1.00) × 1.31 = 3153 × 1.31 = 4130 = 自己 131%
```

低等级玩家身上天级直接打到 **131%**（实测）。修法：材料系数乘在**境界标尺**上，
`min()` 作用在最终值 —— 好材料只在没撞顶时有收益。

### 6.2 `fight()` 的傀儡输出漏了结阵（第二轮遗留）

`core.fight` 原来写：

```python
_pup_atk = _pc0.puppet_attack(puppet, p) * max(1.0, puppet_flame_mult)
```

`puppet_attack` **不含结阵**，而 `monster_scaled` 的怪血反解走的是
`puppet_expected_damage(..., formation_n, ...)` **含结阵** —— 于是带 3 具傀儡时
怪血按 +30% 变厚、傀儡实战却只打单具输出，**带结阵反而吃亏**。

修：`_pup_atk = puppet_expected_damage(puppet, formation_n, flame_mult=..., p=p)`，
并加源码级守门 `test_fight_single_source`（AST 查 `_pup_atk = _pc0.puppet_expected_damage(`）。

### 6.3 封顶必须管最终值（不是单具）

结阵 ×1.30 与异火 ×1.30 都能把单具封顶撑破。所以封顶落在
`puppet_expected_damage` 的 `total` 上，`puppet_attack` 里的那次只是卡面用的单具视图。

## 8. 已知边界（设计选择，不是 bug）

1. **lv95+ 普通天级会相对变弱**（73% → 61%）。这是「材料决定上限」的必然结果，成长路径是
   换北龙王之躯（→ 三星斗圣）。不打算给普通斗尊躯额外补偿。
2. **结阵在天级贴顶时无输出收益**（被 CAP 收口）。结阵的价值落在**护主概率 +6%/具**上。
   要在结阵时突破 95% 就破了「不抢风头」红线。
3. **`body_realm` 是主口径、`body_name` 只是标签**。库里存在「强者之躯（斗尊）」这种
   名字与境界不一致的老数据，实现按**字段值**算（更忠实于记录），不做名字反查。
4. **手搓傀儡（测试直接给 dict）没有 body_realm 时走回落值**，不参与「料好更强」的判定。
