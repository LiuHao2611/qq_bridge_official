## §3 优化说辞清单（重点三类，逐条可直接替换）

> 标注说明：【原文】= 逐字原著台词，可当角色说话；【设定旁白】= 依原著设定写的叙述句，只做旁白；
> 【语汇替换】= 只换词不改结构，风险最低。**所有新文案玩家可见版均不含任何考据/出处声明**。

### 3.1 突破成功（最高优先级，现状最单调）

**现状**（`commands.py:769-770`）：
```
✨ 突破成功！由【斗者一星】晋入【斗者二星】。气血斗气已满。
✨ 境界突破！由【斗者九星】晋入【斗师一星】。气血斗气已满。
```
问题：不管从斗之气到斗帝，永远是同一句「由X晋入Y，气血斗气已满」——**没有原著境界质感**。

**优化后（按境界走专属破境旁白，一句一境）**：

| 触发（新境界） | 新文案 | 依据 |
|---|---|---|
| 斗者 | `气机沉入丹田，一缕气旋缓缓成形——你，终于成了斗者。` | 【设定旁白】聚气成气旋 |
| 斗师 | `气旋翻涌，斗气由气凝液，一层薄纱自体表浮起——【斗师】。` | 【设定旁白】气态化液态、斗气纱衣 |
| 大斗师 | `液态斗气凝成棱形斗晶，铠甲自肤下升起——【大斗师】。` | 【设定旁白】斗晶、斗气铠甲 |
| 斗灵 | `斗晶生刺，一柄斗气凝成的兵刃落在掌心——【斗灵】。` | 【设定旁白】斗气凝物 |
| 斗王 | `斗气化翼，双翼乍展，你第一次离地三尺——【斗王】。` | 【设定旁白】斗气化翼 |
| 斗皇 | `天地间同属性能量奔涌入体，足下虚空微微下陷——【斗皇】。` | 【设定旁白】调动外界能量 |
| 斗宗 | `一步踏虚，脚下空间泛起涟漪——【斗宗】。` | 【设定旁白】踏空而行 |

### 3.2 遭遇怪物 / BOSS（第二优先级）

**现状**：
```
⚔️ 遭遇 3 敌 · 4回合 · 大捷
💥 佛怒火莲 6240（力量·斗气）
🎯 战果 斩获 2 · 修为 +1800 · 金币 +900
```
问题：像战报表格，没有「遭遇」的临场感；BOSS 虽有登场描写，但普通怪和收场句仍是表格。

**优化后**：

| 节点 | 新文案 | 依据 |
|---|---|---|
| 普通遭遇（替代首行） | `⚔️ 山道狭窄，{n} 道气息迎面压来——一战不可避免。` | 【设定旁白】不冒充台词 |

### 3.3 炼药成功 / 失败（第三优先级）

**现状**：
