## 1. 背景：为什么这轮要换做法

### 1.1 你的三次反馈（原话）

3. 「还有 boos 有台词，也应该有出场描述，」

### 1.2 前两轮为什么没洗干净

**根因是治理位置错了，不是漏改了几条字符串。**

`FACTIONS` 这份宗门数据被 **6 处**消费：

```
factions.FACTIONS
├── commands.cmd_faction()        → 宗门口令文本
├── card.build_faction_data()     → 宗门卡「传承异火 / 代表人物 / 斗技统计」
├── core.skill_pool()             → 斗技池（本宗技名进四槽）
├── card.build_roster_data()      → 名录入门卡
├── card.build_skills_data()      → 斗技卡
└── 图鉴 / 加入门派文案
```

第一轮只在 `commands.py` 里逐句改文案 → 宗门卡照样把 `[C1]`、`[游戏原创]`、`第X章「标题」` 印出来。
**只要有一处消费点忘了洗，玩家就会看到台账。** 所以第三轮把净化搬到**数据层**，导入即生效，消费方怎么写都漏不出去。

## 4. 逐项改动详解

### 4.1 数据层净化（本轮的核心）

`factions.py` 导入时递归剥标签，**只动展示副本**：

```python
_CITE_TAG_RE = re.compile(r"\s*\[(?:[CGS]\d+|原著|游戏原创|游戏核心)\]")
_META_PHRASE_RE = re.compile(
    r"[（(]?\s*(?:游戏自设|游戏原创|原著无同名设定|原著未载|原著无载|原著无)\s*[）)]?")

def _clean_faction_text(t: str) -> str:
    s = _CITE_TAG_RE.sub("", str(t))
    s = _META_PHRASE_RE.sub("", s)
    s = re.sub(r"[（(]\s*[）)]", "", s)          # 清掉被掏空的括注
    s = re.sub(r"[，、]{2,}", "，", s).strip(" ，、")
    return s

def _strip_cite_tags(obj):                       # dict / list / tuple 全覆盖
    ...
_strip_cite_tags(FACTIONS)
```

剥之前先快照，供门禁与文档追溯（**禁止渲染**）：

```python
FACTION_CITE_LEDGER: tuple[tuple[str, str], ...] = tuple(_walk_cites(FACTIONS))
# 233 条 (路径, 原文)，例：('/xiaojia/skills[0]', '狂狮怒罡（玄阶中，仅族长可修）[C3]')
```

**效果**：`FACTIONS` 里 233 处带标记的字符串，展示侧全部变干净（`BAD=0`）。

### 4.5 修真 bug：目标侧闪避从来没被结算过

**症状**：玩家打怪只算防御减伤，怪身上挂着「身法」也不会闪。

**连锁后果**：

1. 怪物侧的 `evade` 类效果 = 纯文案；
2. 玩家 **7 门**「控场·压闪避」斗技压的是**不存在的属性**：
   凶熊碎地拳 / 青湮剑罡 / 湮幻刺 / 气化天地 / 邪风斩 / 光耀印 / 千幻玄冰刺。

**修法**（`core.py`，19 行）：

```python
# fight() 内
m_fx["evade"] = max(0.0, min(0.9, float(mon.get("dodge") or 0)))   # 默认 0

# _hit() 内，位置在 on_hit 之前（闪掉了就不该挂毒/降攻）
if fx_target is not None:
    t_ev = max(0.0, float(fx_target.get("evade", 0)) + fx.target_evade_delta(fx_target))
    if t_ev > 0 and rng() < t_ev:
        return {"dmg": 0, ..., "evaded": True, "notes": ["被对手闪过"]}
```

**关键红线**：`t_ev <= 0` 时**绝不掷骰**。否则普通战斗的 rng 序列整体错位，
`test_battle_review` 的 218 条逐招快照会一起红。默认 `mon["dodge"]` 不存在 → 0 → 逐字节不变。

### 4.6 门禁重写：`_verify_flames.py`

旧门禁要求「展示串必须带章节引用」，这与你「不许印原著」的要求**正面冲突**。
本轮把职责拆开，四条硬规则：

1. 展示串**不许**有 `第X章「…」`、`[C1]/[原著]/[游戏原创]`、`原著/语料/考据` 等出戏词；
2. 每个有 `flames` 的门派必须有台账（`FACTION_FLAME_EVIDENCE`），且**条数 ≥ 展示条数**；
3. 台账每条至少一个 `第X章「标题」`，且必须能在原著语料章节表里**逐字找到**；
4. 展示串与台账里的异火名必须在原著正文真实出现，且不得出现已知错名（八荒破灭焱 / 风灵青焰 …）。

## 5. 「技能效果真落地」怎么证的

`tests/test_doupo_skill_effects_land.py`（新增 361 行）对 skill_book 声明的 **16 种** effect 类型，
逐条做**同参数对照实验**：带效果打一场、不带效果打一场，**只看日志最终数值**，不看文案。

| 效果 | 观测点 | 实测 |
|---|---|---|
| empower 增幅 | 总伤害 | 7280 vs 5200 |
| pierce 破防 | 对高防目标总伤害 | 1260 vs 715 |
| cond 条件加伤 | 条件满足 / 不满足 | 7800 vs 5200；不满足 = 5200（不加） |
| chain 连击 | 第 3 段单伤 | `[1040, 1040, 1560, 1560, 1560]` |
| lifesteal 吸血 | 同怪存活回合数 | 14 回合 vs 10 回合 |
| dot 持续伤害 | 敌方额外掉血 | 直伤 5200 + 毒 4680 |
| debuff_atk 降攻 | 敌方单击承伤 | 首击 96 vs 160 |
| debuff_evade 压闪避 | 命中次数 | 压制后 5 vs 压制前 2（目标闪避 25%） |
| debuff_heal 减疗 | 目标回血倍率 | 0.5（3 条状态级断言） |
| stun 眩晕 / root 定身 / knockback 击退 | 敌方出手次数 | 294 / 294 / 295 vs 300 |
| silence 禁技 | 敌方技能施放次数 | 291 vs 300 |
| reflect 反伤 | 反弹伤害 | 560，且不计成 DoT |
| reduce 减伤 | 玩家承伤 | 1520 vs 1600 |
| evade 自身闪避 | 闪避次数 | 4 次 |

外加一条**元门禁**：`skill_book` 里声明的效果类型必须全部在 `skill_effects.EFFECT_LABELS` 里
（防止以后又写一个「只有描述、没有实现」的新类型）。

> `debuff_atk` 那格特意用**单击**而非总额：降攻会拖长战斗，总额反而变大（实测 1632 vs 1600）。
> 这是"总量口径"的经典陷阱，不是机制没生效。

## 8. 已知弱点与待你拍板（我没有擅自改）

### 8.1 压闪避的"越需要越压不上"

控场效果是**命中后**才挂上的。目标闪避 >30% 时，你这招本身先被闪掉 → 压闪避永远挂不上。
实测：目标闪避 25% 时能压（命中 3→5）；35% / 50% 时压了个空。

三个可选修法，等你选：

- **A（最小改动）**：`role in ("控场","功能")` 的技能不吃目标闪避（气机锁定，讲得通）；
- **B（改语义）**：`debuff_evade` 在"被闪过"时也生效一半（压制是气场，不必打中）；
- **C（不动）**：接受它只是"对不怎么会闪的怪更狠"，不改。
