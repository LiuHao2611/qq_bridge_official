## 一、原著事实边界（设计不得与之冲突）

全部来自台账，按主题重列。这一节是「宪法」，§三任何设计与之冲突以本节为准。

### 1.1 傀儡是什么
- 叫「天妖傀」，是远古流传的**傀儡之技**，载体是一卷从魔炎谷抄家所得的竹简（E01）。
- 竹简总纲：三物齐聚——躯体为器、灵魂为引、魔核为心，再配诸多材料；「等级之差，取决炼制材料**以及炼制之火**」（E02/E03/E04）。
- 分天/地/人三等，以皮肤色辨：天=金、地=银、人=铜（E05）。
- 战力对应：人级最低，地级≈5-6星斗宗，天级≈斗尊可一战（E09）。

### 1.2 档次不是炼出来的，是「炼+雷淬」两级台阶
- **首次炼出即人级铜**，即使用斗宗躯体+七阶魔核+斗宗灵魂（E06）。
- 人→地：靠一次丹雷洗礼（E07）。
- 地→天：靠长期大量雷霆淬炼（五色丹雷等），「需要何等庞大的雷霆之力」（E08/E41）。
- 修复也靠雷霆，与升级同源（E42）。

### 1.3 材料与五步操作
- 躯体：强者尸体，且须**冰封保鲜**（E10）；「躯体最为重要」（E33）。
- 去尸气：尸气带死者意念，不驱净则灵魂难与躯体融合；耗时约三小时（E11/E12）。
- 开洞装机：胸膛放魔核、额头放灵魂（E13）；魔核有属性（火），与炼制之火配套（E14）。
- 炼神智：灵魂须炼到神智「烟消云散」，无我识才可入料（E15）。
- 金属淬体：暗金溶液涂满全身改造身体强度，活人会爆体而亡，故只能用尸体（E18）。
- 三者契合：达「完美契合度」才激活，等号七日（E17）。
- 火候：一高一低同时控两种火（恒温淬尸+高温熔金属），需「极高的火焰操控能力」，靠五轮离火法做到（E16/E25）。

### 1.4 使用者自身门槛（用户反复强调，逐条有原文）
- 灵魂境界四层凡/灵/天/帝，**绑炼药师品阶**：七品才可能触灵境，很多炼药师卡在七品正因灵魂境界（E22/E23）。
- 灵魂力量随疯狂炼丹提升——是炼药产物，不是凭空属性（E24）。
- 控火靠修习法门+多炼药实战（E25）。
- 异火来源三途：榜单稀有资源（E26）、强者传承（E27）、势力封印+争夺降服（E28）。
- 炼制全程持续输入斗气，火鼎「按天烧」，连前斗尊都撑不住（E29/E30）。
- 炼制者本人已是斗宗（所用材料档次明示），自忖天妖傀要斗尊材料（E31）。**原著未写死具体星级**，故星级下限是 `[调参]`，非原著定值。

### 1.5 认主与忠诚
- 认主只用自己咬舌尖的一滴含灵魂印记的血，不消耗任何额外道具（E19）。
- 认主瞬间灵魂「分成两部分」→ 要求持有者灵魂够强（E20）。
- 结果：绝对忠诚，永不背叛，可命令其攻击主人自己（E21）。

### 1.6 战斗定位
- 傀儡无法施展斗气/斗技，纯肉身力量（E32/E33）。
- 基础傀儡无智慧、无战斗经验、古板，靠主人操控（E34）。
- 但肉身拳击威力「不比斗技弱」（E35）。

### 1.7 进阶玩法（旧版全漏，本版必补）
- 可复数持有：自己炼的 + 收服的十具地妖傀（E36）。
- 收服他人傀儡：抹除制造者灵魂印记、留下自己的印记（E37）。
- 结阵：多具傀儡连接能量成循环，临时进化、战力大涨（E38）。
- 自愈：受损裂缝在银芒下飞速消失（E39）。
- 残魂融合：熔入战斗残魂→有经验、会主动出手（北王式，E40）。
- 雷霆分级供能：丹雷<五色丹雷<黑魔雷，对应淬炼强度（E41）。

### 1.8 防误传
- 原著**没有**「傀儡术」「傀儡师」「人妖傀」三个词，全书 0 命中（E43/E44）。
- 「人级」是等级，不是独立傀儡名；原著名词只有天妖傀/地妖傀。

## 三、核心设计

### 3.1 价值主张
原著爽点 = 「拿强者尸体炼忠诚打手 + 长期雷霆养成」。游戏里转成：
- **资格有门槛**：五道资格（§3.5），缺一不可——这是「最基础傀儡」的灵魂。
- **炼制有过程**：五步不可跳，按天计时，斗气续航（E11/E12/E17/E30）。
- **初始很低、成长很长**：首炼人级铜，靠雷淬→地→天（E06/E07/E08）。
- **战斗有价值但不失衡**：傀儡输出必须进反解（§3.2）。
- **有进阶玩法**：多具+结阵、收服他人傀儡、残魂融合（§3.7/§3.8）。

### 3.2 数据结构（存档新增字段，挂 §一事实）
`core.create_player()` 的 `st` 加字段，`p.get()` 兜底，不改 SQLite schema：

```
"puppet_roster": [],      # 傀儡列表（复数！对应 E36）：每具一个 puppet 对象
"puppet_lore": False,     # 是否已读竹简习得傀儡之技（E01）
"puppet_ready": False,    # 五道资格达标标记（§3.5），达标置 True 永久有效
"puppet_active": 0,       # 当前出战傀儡在 roster 中的下标
# 五道资格全部挂靠已有系统，不新增凭空字段：
#   境界 ← p["lv"]（E31）；灵魂境界 ← p["alch"] 品阶映射（E22/E23/E24）
#   控火 ← 炼药次数/高阶丹药记录（E25）；异火 ← p["flames"]（E26/E27/E28）
#   斗气总量 ← mp_max(p)（E29/E30）
```

单个傀儡对象（`puppet_roster[i]`，一人可多具，符合 E36）：

```
{
  "name": "地妖傀·玄",
  "tier": 0,              # 0=人级铜 / 1=地级银 / 2=天级金（E05）
  "tier_name": "人妖傀"? NO —— 人级傀儡，原文无「人妖傀」一词（E44）
  "body": {               # 躯体（E10/E33：躯体最重要）
    "name": "地魔老鬼之躯", "realm": "斗宗", "star": 7,
    "fresh": True, "fresh_until": <ts>   # 冰封保鲜，过期不可入料（E10）
  },
  "core": { "tier": 7, "attr": "火" },  # 魔核阶+属性，属性配炼制之火（E14）
  "soul": { "source": "魂殿铁护法", "strength": 900,
            "mind_stripped": True },    # 铁律：无我识才可入料（E15）
  "metal": { "name": "暗金玄铁", "grade": 2 },  # 加固/定皮肤（E04/E18）
  "skin": "铜",           # 铜/银/金，须与 tier 一致（E05/E06）
  "purity": 0,            # 雷淬进度 0~100，达标升 tier（E07/E08/E41）
  "bonded": True,         # 已认主：自己的血，永不背叛（E19/E21）
  "awakened": False,      # 熔残魂改良：会主动出手（E40）
  "origin": "self",       # self=自己炼 / captured=收服他人（E37）
  "born": <ts>
}
```

> 字段逐条对应 E 编号，实时属性由 `puppet_stats(p, i)` 从结构推导、不落盘
> （与 `stats()` 同构，避免第二真相源）。

### 3.3 战斗接入（关键决策，红线）
**方案：每回合追加一次「傀儡击」，并把期望输出计入怪物血量反解。**

1. `fight()` 内仿 `hero_aid`，玩家 `_hit` 后、怪反击前插入傀儡出手（若无傀儡则跳过）：
   - 伤害口径独立：`puppet_hit = 傀儡肉身攻击 × mitigation(m_def)`，**不吃 mp、不吃斗技槽**（E32/E33）。
   - log：`{"dmg":..., "kind":"傀儡击", "puppet":True, "helper":"地妖傀·玄", "tier":0, "move":"傀儡击"}`，经 `_mark()` 补齐；渲染层只 `.get()`。
2. **反解必须成对改**（红线）：傀儡每回合期望输出加入 `damage_schedule()` → `cum_damage` 变大 → `monster_scaled` 算的 `m_hp` 同步变大 → TTK 不变。否则全员多打手→秒杀、胜率破表、守门必红。
   - 落地：做成 `puppet_expected_damage(p)` **唯一函数**，`fight` 与 `damage_schedule` 都只调它，加注释+守门锁死同源。
3. `power()` 把傀儡折算值计入，面板/排行口径一致。
4. 多具傀儡：`puppet_active` 指定的那一具出战；结阵时（§3.8）多具同时出手并触发阵法增益。

**否决的备选**：被动属性加成（看不到出手，违背「第二行动主体」）；纯概率触发（炼制成本高却可能整场不出手）；不计反解纯加输出（破坏平衡）。

### 3.4 属性与数值（对齐「属性↔战斗强关联」硬要求）
```
puppet_attack(p, i) = 躯体基值(realm/star) + 魔核阶数×K1 + 灵魂强度×K2   # [调参] K1/K2
puppet_stats(p, i)  -> {"力量":躯体×a, "防御":躯体×b, "体力":躯体×c, "斗气":0}
```
- 主吃**力量**（肉身伤害）与**防御**（躯体硬度），体力做生存；斗气恒 0（E32/E33）。
- 战报归因沿用 `STAT_BATTLE_ROLE` 语义，但另建 `PUPPET_STAT_ROLE`，不污染六维表（守门 `test_battle_depth:206`）。
- 傀儡不吸血、不吃玩家暴击加成——是「稳」的打手，不是「爆发」打手。
- 档次战力锚点（E09）：人级≈斗者~斗师区间 `[调参]`、地级≈5-6星斗宗、天级≈斗尊。用 E09 校准数值，不凭空定。

### 3.5 资格门槛：五道（统一口径，全部挂已有系统）

> 用户三次纠正后的最终口径：灵魂=炼药产物、控火=炼药练出、异火=传承/Boss、境界+斗气=最基本前提。
> 旧版「三闸/四闸」称呼混乱、还造过 `soul_power`/`fire_ctrl` 凭空字段——**全部作废**。
> 本版统一称「**五道资格**」，无凭空字段、无凭空存档键。

```
开通傀儡系统 = ①境界达标 AND ②灵魂境界达标 AND ③控火功底达标 AND ④持有异火
炼制一具时另验 ⑤斗气总量续航（分档，挂 mp_max）
```

| # | 资格 | 原著依据（E） | 挂靠已有系统 `[调参]` | 玩家怎么达成 |
|---|---|---|---|---|
| ① | **境界** | E31（炼者斗宗，自忖天妖傀要斗尊材料） | `p["lv"]`；分档下限 **人级≥斗师、地级≥斗宗、天级≥斗尊**（境界下限原著未写死星级，此为 `[调参]`） | 正常修炼升级，不靠道具 |
| ② | **灵魂境界** | E20/E22/E23/E24 | 炼药师品阶 `p["alch"]`（七品触灵境 `[调参]`）映射凡/灵/天/帝 | 炼药升级（现有 `alch_exp`/`craft`） |
| ③ | **控火功底** | E16/E25 | 炼药次数 / 高阶丹药炼成记录（累计 N 次或炼成≥X品）`[调参]` | 多炼药，尤其高阶丹药 |
| ④ | **异火** | E26/E27/E28 | 已有 `p["flames"]`；来源=宗门传承+精英怪/Boss掉落（沿用现有途径） | 宗门线或打精英/Boss |
| ⑤ | **斗气续航** | E29/E30/E45（火鼎按天烧，炼凶魂需三四天，前斗尊都撑不住） | 分档斗气总量 ≥ 全程消耗(炼魂3-4日+淬尸+契合7日)×系数，挂 `mp_max(p)` | 境界/异火成长撑大斗气池 |

**设计要点**：
- ①②③④一次性达标 → 置 `p["puppet_ready"]=True`，不再反复判；⑤每具炼制时单独验（是消耗/续航，不是资格）。
- 五道**全是玩家已有养成/资源**，形成「修炼+炼药+收异火 → 自然开通」正向引导。
- 对外显文案展示：境界 / 炼药品阶(→灵魂境界) / 炼药功底 / 异火 / 斗气池；用原著称谓，禁「精神力」等自造词。
- 不达标拦截：`炼制傀儡`/`傀儡遗迹` 拦并指出缺哪项；如「境界不足，须斗宗以上」「灵魂境界未达灵境」「斗气不足以撑完七日淬炼」。
- 异火是五道里唯一可靠副本/Boss掉落的（用户明确要求），但仍走既有「传承/精英怪·Boss」途径，不是随便刷；灵魂/控火是炼药产物，副本掉不了。

### 3.6 首次炼制：五步（挂 §1.3，按天计时）
`炼制傀儡` 启动，分步推进、失败点可见；每步对应原文：

| 步 | 操作 | 原文(E) | 判定/失败后果 | 耗时 `[调参]` |
|---|---|---|---|---|
| 〇1 | 验传承 | E01 | `puppet_lore=True`，无则拒「尚未习得傀儡之技」 | 瞬时 |
| 〇2 | 验躯体新鲜 | E10 | `body.fresh` 且未过 `fresh_until`；腐烂不得入料 | 瞬时 |
| 〇3 | 定炼制之火 | E03/E14 | 火属性/强度是独立定档变量，火弱则封顶低档 | 瞬时 |
| 一 | 去尸气 | E11/E12 | 异火高温驱净，火候不足卡住「尸气未净」 | 1 段计时(~3h) |
| 二 | 开洞装机 | E13/E14 | 胸放魔核额放灵魂；魔核属性须配炼制之火，不符则契合打折 | 瞬时 |
| 三 | 炼神智 | E15 | 铁律 `mind_stripped`；带自我意识入料→反噬失败 | 1 段计时 |
| 四 | 三者契合+金属淬体 | E17/E18 | 完美契合度= f(躯体档,灵魂强,火候,魔核匹配)；暗金溶液定皮肤；斗气续航不足则中断、材料不退 | 数段计时(原著七日) |
| 五 | 滴血认主 | E19/E20/E21 | 只用自己的血，验灵魂境界→`bonded=True`；不扣额外道具 | 瞬时 |

**成品定档公式**（接住 E03「材料以及炼制之火」+ E06「首炼即人级」）：
```
首炼 tier 恒 = 0（人级铜），与材料档次无关（E06）——材料档次只决定「这一具的躯体基值/成长上限」
tier 升级 = f(雷淬纯度 purity, 雷霆强度)，人→地→天（E07/E08/E41/E42）
skin 须与 tier 一致（E05）；metal.grade + 淬炼度共同决定 skin（E18）
```

> **关键**：旧版把材料档次直接映射成 tier（斗宗材料→地级）是错的（E06 反证）。
> 本版改为「材料定**初始值/上限**，雷淬定**当前档**」，忠于原著两级台阶。

### 3.7 进阶玩法线（旧版全漏，本版补齐）

**线 A · 雷霆淬炼（升级+修复共用，E07/E08/E41/E42）**
- 消耗雷系材料（丹雷<五色丹雷<黑魔雷，按强度分级）+ 金币，升 `purity`。
- `purity` 达阈值 → `tier+1`（人铜→地银→天金），`skin/tier_name` 同步且一致；天级封顶。
- 修复：受损傀儡（战斗后 `damaged` 标记）用雷淬修复，与升级同源资源（E42）。
- 文案用原著「雷霆淬炼提纯」，产出战斗外 log。

**线 B · 多具持有 + 结阵（E36/E38）**
- `puppet_roster` 可有多具（自己炼 + 收服）；`puppet_active` 指定出战那具。
- 结阵：≥N 具（如 3/10 具 `[调参]`）同场时触发，连接能量成循环 → 临时 `tier` 视觉升级 + 战力加成（E38「银→金」「足以与二星斗尊抗衡」）。
- 数值：阵法加成做成独立函数 `puppet_formation_bonus(p)`，也**必须进反解**（同 §3.3 红线）。

**线 C · 收服他人傀儡（E37）**
- 战斗/副本掉落「无主傀儡」或击败敌方傀儡后，可用灵魂力量抹除制造者印记、留下自己的 → `origin="captured"` 加入 roster。
- 门槛：灵魂境界达标（E20/E22，印记是灵魂层面的操作）；否则抹不掉。
- 收服的傀儡沿用同一 puppet 结构，`bonded=True`。

**线 D · 残魂融合改良（北王式，E34/E40）**
- 基础傀儡古板/无经验（E34）；熔入战斗残魂（须炼到无自我意识，同 E15 铁律）→ `awakened=True`。
- 效果：会主动出手、战斗回看归因标注「有灵」；但**仍不吃 mp/斗技**（E32）。
- `[待定]` 是否首版实现，但 `awakened` 字段先留位。

### 3.8 战斗回看与自愈（E39/E21）
- 傀儡出手进 `p["last_battle"]["log"]`，分类标注「傀儡击/结阵/有灵」。
- 战斗中傀儡受伤 → 标记 `damaged`；战后可用雷淬修复（E42），或按 E39 自愈（银芒修复裂缝）——做成「低伤自愈、高伤需雷修」两档 `[调参]`。
- 认主忠诚设定：傀儡永不背叛（E21），不做「被夺/叛变」负向玩法，避免与设定冲突。

| 决策 | 取舍 |
|---|---|
| 可多具 vs 一具 | **可多具**（E36 原著有十一具），旧版「一具」作废；用 `puppet_active` + 结阵管复杂度 |
| 首炼档次 | **恒人级铜**（E06），材料定上限、雷淬定当前档；旧版材料直接定档作废 |
| 常驻协战 vs 概率外援 | **常驻**，炼制成本高，正反馈必须稳定 |
| 战力计入反解 | 牺牲秒杀快感换平衡；价值在爬塔/周本/PVP 的固定难度 |
| PVP 傀儡 | 切磋双方各带各的（对称）；`[待定]` 需确认 PVP 是否允许傀儡 |
| 术语 | 全用原著称谓（天妖傀/地妖傀/躯魔魂/雷池淬炼），禁「傀儡术/傀儡师/人妖傀」（E43/E44） |

**最大风险**：「反解成对修改」被后来者拆开。对策：`puppet_expected_damage` 唯一函数，`fight` 与 `damage_schedule` 都只调它，注释+守门用例锁死同源。
