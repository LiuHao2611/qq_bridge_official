## 〇、一句话结论

傀儡应当做成**「可养成、常驻协战、按材料档次分级的第二行动主体」**，落点是
`core.fight()` 内仿 `hero_aid` 的注入分支；**但战力必须计入怪物血量反解
（`damage_schedule`/`cum_damage`），否则全员多一个打手会直接击穿胜率与 TTK 平衡**。
使用者门槛（传承/控火/灵魂/斗气）在原著里是硬条件，游戏里要转译成**可消费的资源门槛**，
不能白送——这是「最基础傀儡」这件事在游戏里的灵魂。

## 三、核心设计

### 3.1 定位：养成深度，不是数值白送

原著傀儡的爽点是「**拿强者尸体当材料炼出忠诚打手**」，本质是**资源→战力的转化 + 长期养成**。
所以游戏里的价值主张应当是：

- **炼制有门槛**：传承 + 三主材 + 辅材 + 控火/灵魂/斗气条件，缺一不可（对应考据 §一）。
- **升级有奔头**：人(铜) → 地(银) → 天(金)，靠「雷池淬炼」，对应原著雷霆提纯。
- **战斗有价值但不失衡**：见 §3.3，这是唯一需要动平衡内核的地方。

### 3.2 数据结构（存档新增字段）

加在 `core.create_player()` 的 `st` 字典里，`p.get(...)` 兜底，不改 SQLite schema：

```
"puppet": None,          # 当前傀儡存档；None=未拥有。结构见下
"puppet_lore": False,    # 是否已习得"天妖傀"传承（读竹简后置 True）
"puppet_ready": False,   # 四闸开通标记（§3.8）：达标后置 True，永久有效
# 四闸挂靠游戏已有系统，不新增凭空字段（见 §3.8）：
#   境界 ← p["lv"]；灵魂境界 ← p["alch"]（炼药师品阶）；
#   控火 ← 炼药次数/高阶丹药记录；异火 ← p["flames"]（宗门传承/精英怪·Boss 掉落）
#   另有分档斗气总量门槛，挂靠 mp_max(p)，不另存字段
```

单个傀儡 `puppet` 结构（一人一具，符合原著「最贴身护卫」的单数设定；不做军队）：

```
{
  "name": "地妖傀·玄",
  "tier": 1,              # 0=人级铜 / 1=地级银 / 2=天级金
  "tier_name": "地妖傀",
  # —— 三主材：每一件都忠实记录原著对成品的影响，不是装饰字段 ——
  "body": {                # 躯体（原著「炼制傀儡，躯体最为重要」）
    "name": "地魔老鬼之躯",
    "realm": "斗宗", "star": 7,   # 死者生前境界星级 → 躯体基值的主来源
    "fresh": True,               # 🆕 躯体须新鲜/冰封保存（原著两具都是"被冰封的尸体"）
    "fresh_until": <ts>,         # 时效：过期腐烂则不可入料，副本掉躯体带保鲜期
  },
  "core": {                # 魔核（提供能量与属性）
    "tier": 7, "attr": "火",     # 阶数 + 属性；🆕 属性须与炼制之火匹配，否则契合度打折
  },
  "soul": {                # 灵魂（必须已炼掉神智，否则反噬）
    "source": "魂殿铁护法", "strength": 900,
    "mind_stripped": True,       # 铁律：False 不得入料，见 §3.7 步骤三
  },
  "metal": {               # 特殊金属（决定皮肤铜/银/金，与淬炼度共同定 tier）
    "name": "暗金玄铁", "grade": 2,
  },
  "skin": "银",            # 铜/银/金，由 metal + 淬炼度决定，tier 的外显
  "purity": 0,             # 雷池淬炼纯度 0~100
  "bonded": True,          # 已滴精血认主：唯命是从、永不背叛
  "awakened": False,       # 是否熔入残魂获得战斗经验（北王式改良，见 §3.6）
  "born": <ts>,
}
```

字段完整的理由：上一版把三主材压成 `body=字符串 / core=数字 / soul=数字`，结果
「躯体档次决定强弱」「灵魂必须去神智」「金属决定金银铜」三条原著硬约束全丢了——这次
逐条回填。实时属性仍**不落盘**，由 `puppet_stats(p)` 从上述结构 + 玩家境界实时推导
（和 `stats()` 同构），避免「属性漂移」的第二种真相源。

### 3.3 战斗接入（关键决策）

**推荐方案：傀儡每回合追加一次「傀儡击」，并把它的期望输出计入怪物血量的反解基准。**

理由与做法：

1. 在 `fight()` 里仿 `hero_aid`，玩家 `_hit` 之后、怪反击之前，插入傀儡出手：
   - 伤害口径**独立**：`puppet_hit = 傀儡肉身攻击 × mitigation(m_def)`，不吃 mp、不吃斗技槽
     （忠于原著「无法施展斗气、全凭肉身」）。
   - log 条目：`{"dmg":..., "kind":"傀儡击", "puppet":True, "helper":"地妖傀·玄",
     "tier":1, "move":"傀儡击"}`，经 `_mark()` 补齐快照字段。渲染层只用 `.get()`。
2. **必须同时改反解**：把傀儡每回合期望输出加进 `damage_schedule()` 的返回值，
   使 `cum_damage` 变大 → `monster_scaled` 算出的 `m_hp` 同步变大 → TTK 仍是 4.5。
   - 否则会出现「玩家多了打手但怪没变强」→ 全员 2 回合秒杀，`test_battle_depth` / `_balance.py` 全红。
   - 这条是**红线**：傀儡输出与反解必须同涨同落，写成一对函数、同一份系数。
3. `power()`（战力展示）相应把傀儡折算值计入，面板/排行口径一致。
4. 多敌 `encounter`：傀儡与玩家同步出手，不走「整场掷一次」的随机逻辑（它是常驻，非概率）。

**为什么不选另外两种做法**（决策记录）：

| 备选 | 问题 |
|---|---|
| 做成被动属性加成（不加 log） | 看不到傀儡出手，战斗回看里没有它，违背「第二行动主体」的预期 |
| 做成纯概率触发（仿 hero_aid 低概率） | 玩家花了大力气炼制却可能整场不出手，正反馈太弱 |
| 不计入反解、纯加输出 | 直接破坏 TTK/胜率平衡，守门必红，天妖傀会把游戏打穿 |

### 3.4 属性与数值（对齐「属性↔战斗强关联」硬要求）

傀儡的肉身攻击由三材决定，且**在战报里逐维归因**（不能只播一个数字）：

```
puppet_attack(p) = 躯体基值(tier) + 魔核阶数×K1 + 灵魂强度×K2    # [调参] K1/K2
puppet_stats(p)  -> {"力量":躯体×a, "防御":躯体×b, "体力":躯体×c, "斗气":0}
```

- 主吃**力量**（肉身伤害）与**防御**（躯体硬度），体力做生存；斗气恒 0（原著设定）。
- 战报归因串沿用 `STAT_BATTLE_ROLE` 的语义：「力量·肉身」「防御·减伤」，
  但**另建一张 `PUPPET_STAT_ROLE` 映射表**，不污染六维表（守门 `test_battle_depth:206` 要求六维全覆盖）。
- add note：傀儡不吸血、不吃玩家暴击加成——它是「稳」的打手，不是「爆发」的打手。

| 3 | **异火且要够强**（逼尸气/炼神智/淬体全靠异火高温） | `max(p["flames"].values()) ≥ 火候阈值`（宗门传承/精英怪·Boss 掉落所得） | 火强度不足则「尸气难驱、神智难炼」，卡在去尸气步 | `_gate_flame_heat` |
| 4 | **灵魂境界**（七品炼药师机缘触灵境；认主要能"灵魂分半"） | **炼药师品阶 `p["alch"]`** 映射凡/灵/天/帝境（见 §3.8，不新增字段） | 境界不足则无法认主 | `_gate_soul`（读已有系统） |

**关键**：控火（第 2 行）与灵魂（第 4 行）**不是凭空属性，而是炼药等级/炼药功底的产物**——
对应原著「灵魂境界随炼药师品阶提升」「控火靠多炼药练出来」。它们与 §3.8 的开通资格是同一套
判定的两次使用：§3.8 判"能否开通系统"，本节判"这一具能否炼成"。都不新增存档字段。

### 3.6 雷池淬炼（进阶线）

- 消耗雷系材料（现有「雷劫丹」周边 / 天材地宝雷属性）+ 金币，提升 `purity`。
- `purity` 达阈值且材料够 → `tier` +1（铜→银→金），`tier_name` 与皮肤颜色同步。
- 每次淬炼产出一条战斗外 log（不进战斗回看），文案以原著「雷霆淬炼提纯」为据。
- 上限天级（金），不会无限叠加——避免长线膨胀。

### 3.6b 残魂改良线（北王式，非最基础款，但必须留入口）

原著边界：基础傀儡「无智慧、无战斗经验、全靠主人操控」，原文称其「古板」；
北王篇（`第一千五百三十章北王`）萧炎**额外熔入一道残魂**，才造出会主动出手、
有战斗经验的傀儡。这是与「雷池淬炼」并列的**第二条培养线**：

- 雷池淬炼提**强度**（铜→银→金），残魂融合提**灵性**（呆板→会主动出手）；
- 材料：一道带战斗经验的残魂（魂殿强者/北龙王级），且**必须炼到只剩战斗本能、
  无自我意识**（否则反噬，与 §3.7 步骤三同源的铁律）；
- 开关 `puppet["awakened"]`：False=基础款（每回合固定追击），True=改良款
  （可主动出手、战斗回看里归因标注「有灵」）——但**两者都不吃 mp/斗技**（原著硬设定）。
- 这条线默认 `[待定]` 是否首版实现，但数据结构 `awakened` 先留位，避免以后改存档。

### 3.7 炼制五步流程（重写：上一版整段压成一个函数，这是最大的漏）

原著炼制不是「校验材料→产出」，而是**五个有先后、有失败点、有时间成本的操作**。
游戏里做成分段确认（口令 `炼制傀儡` 启动，之后每步可自动推进但失败点必须暴露），
每一步都能对应到原文，玩家看得见「为什么这一步要这个条件」：

| 步 | 操作 | 原著依据 | 游戏判定 / 失败后果 | 时间成本 `[调参]` |
|---|---|---|---|---|
| 〇 | **验躯体新鲜**（前置） | `第九百零五章淬炼`：云山、地魔老鬼两具都是「被冰封的尸体」 | 🆕 `body.fresh=True` 且未过 `fresh_until`；腐烂尸身不得入料（副本掉躯体带保鲜期） | 瞬时 |
| 〇 | **定炼制之火** | `第九百章养魂涎` 竹简：「等级之差，取决炼制材料**以及炼制之火**」 | 🆕 火的属性/强度是**独立定档变量**，与材料共同决定可达 tier；火弱则封顶低档 | 瞬时 |
| 一 | **去尸气** | `第九百零五章淬炼`：尸气带死者意念，不驱净「灵魂很难与躯体融合」，烧了三小时 | 耗异火火候：火强度不足 → 卡住，躯体作废一半（可见提示「尸气未净」） | 1 段计时 |
| 二 | **开洞装机** | 同章：胸膛开洞放魔核、额头开洞放灵魂 | 魔核属性 / 灵魂强度入料；🆕 **魔核属性须与炼制之火匹配**（七阶火魔核配异火，苏千语），不符 → 契合度打折、成品降档 | 瞬时 |
| 三 | **炼神智（去我识）** | 同章：铁护法灵魂的神智被炼到「烟消云散」，只留无识灵魂 | **铁律 `mind_stripped`**：带自我意识的灵魂入料 → 反噬、炼制失败（原著会反抗/逃逸） | 1 段计时 |
| 四 | **三者契合 + 金属淬体** | 同章：躯体/灵魂/魔核达「完美契合度」等了七日；暗金溶液淬体定皮肤 | 三者契合度 = f(躯体档次, 灵魂强度, 火候, 魔核属性匹配)；不足则继续耗时，不达标不出成品 | 数段计时（原著七日） |
| 五 | **滴血认主** | `第九百零六章炼制成功`：一滴含灵魂印记的鲜血落额，灵魂「分成两部分」，永不背叛 | 🆕 只需自己的血（**不消耗额外道具**），验灵魂境界达标 → 置 `bonded=True`，绑定不可交易 | 瞬时 |

**成品定档公式**（接住竹简「取决炼制材料以及炼制之火」）：

```
tier = f(躯体realm/star, 魔核tier+属性匹配, 灵魂strength, metal.grade, 炼制之火强度/属性, purity)
  · 地妖傀配方（原著示例）：七星斗宗躯 + 七阶火魔核(配异火) + 斗宗魂 + 暗金金属 → tier=1 银
  · 天妖傀推算（萧炎自忖）：斗尊躯 + 八阶魔核 + 斗尊魂 → tier=2 金
  · 🆕 炼制之火是独立变量：材料够但火不够强/属性不匹配 → 只能出低档（火是"天花板"）
  · 皮色 skin 由 metal.grade + 淬炼度共同决定，且必须与 tier 一致（守门校验）
```

**时间成本的意义**：原著「炼魂三日、淬体七日」体现的是**斗气续航**与**耐心成本**，
不是可以一键跳过的过场。游戏里用「分段计时 + 斗气总量门槛」表达（§3.5 第 5 条），
避免把最基础傀儡做成「点一下就出」的廉价道具——那会丢掉原著「成本极高」的核心质感。

### 3.8 开通门槛：持有者自身的硬性条件（三次重写：四闸，补境界）

> 用户纠正一：「灵魂和炼药有关，达到炼药师级别才接触魂力层级；控火靠多炼药；
> 异火是宗门传承或精英怪/Boss 掉落」——上一版凭空属性（`soul_power`/`fire_ctrl`）已删除，全部挂靠已有系统。
> 用户纠正二（本次）：「是不是忘了最基本的斗气境界？我大斗师能炼吗，还有斗气值」——
> **确实漏了境界闸**。原著炼制时萧炎已是斗宗、自忖天妖傀要斗尊材料，境界是最基本的前提；
> 且斗气是"按天烧"的持续燃料（天火尊者都支持不了火鼎）。故本版升为**四闸**：境界 + 灵魂 + 控火 + 异火。

#### 设计：四闸全部挂靠游戏已有系统（不新造凭空属性）

```
开通傀儡系统 = 境界达标  AND  炼药师品阶达标(→灵魂境界)  AND  炼药功底达标(→控火)  AND  持有异火（传承/Boss掉落）
```

**斗气值门槛（与境界闸配套，非独立闸）**：原著维持火鼎是按天烧的持续消耗，
且连前斗尊都「支持不了」。游戏里做成 **分档斗气总量 + 分段续航**：
`炼制需斗气储备 ≥ 全程总量(炼魂三四天+淬尸+契合七日) × 分档系数`，斗气见底则中断、材料不退
（§3.5 第 5 条 / §3.7）。这与 `mp_max(p)`（现有斗气上限，随境界/异火成长）挂钩——
**境界越高、斗气池越大，才撑得起高档傀儡**，正好与境界闸互相印证。

**关键修正（相对上一版）**：
- ❌ 删除凭空属性：不再有独立的 `soul_power`/`fire_ctrl` 靠"修法诀/养灵魂"成长。
- ✅ 四闸 = `境界(lv)` + `炼药等级(alch→灵魂境界)` + `炼药次数/高阶丹药记录(→控火)` + `异火(flames)`，
  **全是玩家已有的养成/资源**，形成「修炼+炼药+收异火 → 自然开通傀儡」的正向引导。
- ✅ **异火闸可以靠副本/Boss 掉落**（用户明确要求）——与四闸中其余三闸（境界/灵魂/控火，均为修炼/炼药产物）不同，异火本来就是可获取的
  资源；但它走的是**宗门传承和精英怪/Boss 掉落**这两条既有途径，不是副本里随便刷。
- ✅ 灵魂境界用原著四层名（凡/灵/天/帝），与炼药品阶挂钩；认主"灵魂分半"作为**灵境的门槛理由**
  （灵境才够强），逻辑闭环。
- 一次性开通 `p["puppet_ready"]=True`：四闸达标后记标记，不再反复判定。

#### 与 §3.5 / 认主消耗的关系（消除冲突）

- §3.5 曾写「认主扣 `soul_power` 一份」、又曾写「改为消耗精血材料道具」——**两者皆作废**。
  原著认主只用「一滴蕴含灵魂印记的自己的血」，**不扣任何字段、不消耗额外道具**；
  认主是**灵魂境界达标后的自然能力**。
- §3.5 表格第 2/4 行的「`fire_ctrl`/`soul_power`」字段**一并作废**，以本节为准。
- 逻辑顺序：**境界达标 + 炼药升级 + 多炼药 + 收异火 → 四闸自然达标开通 + 斗气池够 → 进副本攒材料 → 五步炼制**。

#### 对外显与文案的要求

- 傀儡卡/人物卡「资格」行改为展示四项：**境界 / 炼药品阶（→灵魂境界）/ 炼药功底 / 异火**，
  让玩家看到"我几星斗者、炼药到几品、还差几次高阶丹药、有没有异火"，而不是抽象数值。
- 文案用原著称谓：「斗者/斗师/斗宗…」「灵魂境界·凡境/灵境」「控火术」「异火（传承/降服）」，
  不许写「精神力」等自造词。
- 四闸不达标时 `炼制傀儡`/`傀儡遗迹` 都拦并指出缺哪项——尤其提示"先修到斗师/斗宗境界/
  提升炼药等级/多炼药/收服异火"，把门槛变成**明确的养成目标**，而非死路。
  **大斗师想炼地级傀儡，明确提示「境界不足，须斗宗以上」**。

## 七、决策记录与风险

| 决策 | 取舍 |
|---|---|
| 一人一具 vs 多具 | 选**一具**，原著「最贴身护卫」是单数；多具会让反解与养成都失控 |
| 常驻协战 vs 概率外援 | 选**常驻**，炼制成本高，正反馈必须稳定 |
| 战力计入反解 | 牺牲「遭遇战秒杀快感」，换平衡不破；傀儡价值在爬塔/周本/PVP 的固定难度 |
| PVP 中的傀儡 | 切磋双方各带各的（对称）；掠夺是打虚拟 NPC，给被掠夺方也配一具同级傀儡以免变成白给——`[待定]`，需先确认 PVP 是否允许傀儡 |
| 术语 | 全用原著有的「天妖傀/地妖傀/躯魔魂/雷池淬炼」，不造「傀儡师/傀儡术」 |

**风险**：最大的风险不是代码量，而是「反解成对修改」是否被后来者拆开。对策：把
`puppet_expected_damage` 做成**唯一函数**，`fight` 与 `damage_schedule` 都只调它，并加一条
注释 + 一条守门用例锁死「两处同源」。谁想只改一处，测试立刻红。

## 九、玩家一条线（获得 → 培养 → 使用）

> 按玩家真实操作顺序串起全程；三段读写**同一个 `p["puppet"]`**，前一段产物是后一段输入。

### 阶段一 · 获得（口令 `炼制傀儡`，五步不可跳，详见 §3.7）

| 步骤 | 玩家视角 | 代码/存档 |
|---|---|---|
| **① 开通资格（前置）** | 境界达标、炼药到一定品阶触灵魂境界、多炼药练控火、有异火 → `puppet_ready=True` | §3.8 四闸 `puppet_gate()`（读 `lv`/`alch`/炼药记录/`flames`）；不达标则拦并提示去修炼/炼药/收异火（大斗师提示"须斗宗以上"） |
| 习得传承 | 拿到「天妖傀竹简」类道具 | `p["puppet_lore"]=True`；无传承直接拒绝 |
| **练控火** | 多炼药、炼高阶丹药，控火自然精进 | 由炼药次数/高阶丹药记录推导（**不新增字段**） |
| **备异火** | 宗门传承 或 打精英怪/Boss 掉落 | `max(p["flames"].values()) ≥ 阈值`（沿用现有异火获取途径） |
| **蓄灵魂** | 炼药师品阶上去，灵魂境界随之提升 | `p["alch"]` 映射凡/灵/天/帝境（**不新增字段**） |
| 备三主材+金属 | 躯体(带境界星级)/魔核(带属性)/灵魂/特殊金属 | 四类齐全达阶，走 `craft` 校验 |
| **① 去尸气** | 异火高温驱尸气 | 火候不足卡住，提示「尸气未净」 |
| **② 开洞装机** | 胸膛放魔核、额头放灵魂 | 属性/强度入料，属性不符则成品打折 |
| **③ 炼神智** | 把灵魂神智炼到无我识 | `mind_stripped` 铁律，带识入料→反噬失败 |
| **④ 契合+淬体** | 三者契合、金属溶液定皮肤（按天计时） | 斗气续航不足则中断、材料不退 |
| **⑤ 滴血认主** | 灵魂境界达标，滴印记精血，永不背叛 | 验灵魂境界 → `bonded=True`，写 `p["puppet"]`（**不扣凭空字段**） |

### 阶段二 · 培养（口令 `傀儡 淬炼` / `傀儡 融魂`）

### 贯穿字段

`p["puppet"]` 单一真相源：炼制**写入** → 淬炼**改 purity/tier** → 战斗**读它出伤害**。
实时属性由 `puppet_stats(p)` 从结构推导、不落盘；老档 `None` 即「未拥有」，`.get` 兜底，DB schema 不动。
