## 0. 一页速览

**核心发现：25 个宗门目前战力极差 = 0，入门异火全相同，玩法几乎无差异。**

真跑探针 `tmp/probe_faction_diff.py` 对 25 派逐一建号：

| 指标 | 25 派结果 |
|---|---|
| 初始战力 | **2937（全部相同，极差 0）** |
| 入门异火 | **火云水炎（全部相同）** |
| 入门技能数 | 1（全部相同） |
| 已有宗门级特殊规则 | **仅魂殿 1 个**（吞噬修为 + 锁死转宗） |

→ 玩家选什么宗门，除了技能名字和一句介绍，**体验上没有区别**。这就是可玩性低下的根因。

**建议做 6 条宗门特色规则，分三档：**

| 优先级 | 宗门 | 特色机制 | 原著依据 | 落地形态 |
|---|---|---|---|---|
| **P0** | 古族 | 血脉等级 → 族纹阶级 → 属性加成 | 第1307章「血脉等级，族纹！」 | 等级驱动的被动成长 |
| **P0** | 丹塔 | 丹会资格 → 丹会排名 → 炼药加成 | 第154/1013章 | 炼药/丹药专属规则 |
| **P0** | 蛇人族 | 血脉进化 + 封印咒 | 第217章 / 第110章 | 战斗控制 + 成长线 |
| **P1** | 太虚古龙族 | 空间穿梭 → 闪避/先手 | 第961/1172章 | 战斗被动 |
| **P1** | 毒宗 | 厄难毒体 → 以毒养战 | 第154/901章 | 高风险高回报被动 |
| **P1** | 天府联盟 | 四派结盟 → 联盟加成 | 第1430/1432章 | 跨宗门协同 |
| P2 | 炎族 / 冰河谷 / 风雷阁 | 火焰掌控 / 体质克制 / 身法 | 对应章节（见 §3.7） | 小额特色，锦上添花 |

共同设计原则（沿用魂殿已验证的模板）：**纯函数判定 + 战斗/结算钩子 + 不改老存档语义**。

## 3. 候选机制 · 逐条原著证据

### 3.1 古族 — 血脉等级 + 族纹（P0 强推）

**原著证据**：

> 第1307章「血脉等级，族纹！」：「六颗星辰…『翎泉，黑湮军七统领，一星斗尊实力，六品血脉等级，经长老院决议商讨，予金色族纹！』」

> 第1313章：「勉强达到九品血脉吧…一枚璀璨到了极点，甚至隐隐有着一种七彩色泽流转的族纹」

> 第990章「古界」：「传说一个人若是能够达到斗帝阶别，血脉将会有所改变，而其后人，也是会因此而得益…一些好运者，还能由血脉之中继承到一些斗帝的能力」

**设定要点**：血脉分品级（一至九品），族纹颜色随品级升（金 → 紫金 → 七彩），是**等级驱动的成长线**，且古族有黑湮军军衔体系。

**为什么强推**：这是全原著最成熟、最可视化的「宗门成长系统」，天然适合做成随玩家等级解锁的被动加成，且族纹配色已有游戏美术依据。

### 3.2 丹塔 — 丹会资格 + 排名（P0 强推）

**原著证据**：

> 第154章「三千焱炎火」：「斗气大陆每三十年，会举办一次炼药界最为盛大与影响力的丹会，而有资格主持的势力，自然便只有丹塔」

> 第1013章「当年旧事」：「此次丹会前十的人，似乎能够得到收取那『三千焱炎火』的资格」

**设定要点**：丹塔是炼药师等级制度的创立者；丹会三十年一届，前十可收三千焱炎火；药尘、丹塔三巨头都是丹会冠军。

**为什么强推**：项目已有完整的炼药系统（`alchemy_settle`、丹方、品阶）和异火系统，**这是唯一能天然接入现有炼药主线的宗门规则**，几乎不用造新系统。

### 3.3 蛇人族 — 血脉进化 + 封印咒（P0）

**原著证据**：

> 第217章「七彩吞天蟒」：「那堪与斗圣强者相抗衡的远古异兽，被人称为七彩吞天蟒…也是美杜莎女王的新躯体」

> 第110章：「中了她的蛇之封印咒，不仅身体急速衰老，而且连实力，也是被封印在了斗灵级别」

**设定要点**：蛇人血脉可进化为七彩吞天蟒（原著明确「血脉稀薄，进化几率微薄」）；蛇之封印咒能压制对手实力。

**为什么推荐**：封印咒是**现成的控制类技能题材**（现有 `debuff_atk` / `root` 效果原子可直接承载），血脉进化是长线成长目标。生产库虽无蛇人族玩家，但新号会随机分到。

### 3.4 太虚古龙族 — 空间穿梭（P1）

**原著证据**：

> 第961章「追杀」：「空间穿梭是斗尊强者才能办到的事…那家伙速度极为恐怖」

> 第1172章「龙印」：「太虚古龙擅长空间穿梭，而紫研偶尔会展现出来的神通，也是与空间有着关系」

**设定要点**：太虚古龙以空间能力著称，第1172章「龙印」明确「太虚古龙擅长空间穿梭，而紫研偶尔会展现出来的神通，也是与空间有着关系」，并提到她凭此自由进出丹界。

**为什么推荐**：现有 `evade` / `after_move` 效果原子可承载，做成「闪避率 + 战斗脱身」被动，辨识度高。

### 3.5 毒宗 — 厄难毒体（P1）

**原著证据**：

> 第154章「厄难毒体」：「这种体质，被人称为天生毒体或者厄难毒体，因为这种毒体的出现，基本上就是带来厄难…一个帝国变成千里毒土」

> 第901章「厄难毒体提前爆发」：「一旦毒气入脑，那后果…」

**设定要点**：以毒养战、强但会失控——天然的**高风险高回报**机制。注意：第154章「厄难毒体」明确厄难毒体是**小医仙个人体质，不是毒宗传承**，所以建议写成「毒宗秘法·仿毒体」而非「毒宗自带厄难毒体」，避免犯异火考据里同样的错误（把个人所有写成门派传承）。

### 3.6 天府联盟 — 四派结盟（P1）

**原著证据**：

> 第1430章「天府联盟」：「我们的联盟，便号称『天府』吧，以天为府」

> 第1432章：「当星陨阁，丹塔，花宗，焚炎谷四大势力宣布结成所谓『天府联盟』的消息传出来时，整个中州…炸得瞬间沸腾」

**设定要点**：天府是**四派联合**，不是单一宗门。

**为什么推荐但仅 P1**：可以做「联盟成员之间互相加成」的社交/协同玩法，但当前 25 派数据结构把天府当普通单门派，要做「结盟」需额外建模，成本高。

### 3.7 P2 备选（证据已核，收益较小）

| 宗门 | 原著证据 | 可做形态 |
|---|---|---|
| 炎族 | 第1474章「荒破灭焱」火炫「在长老们的帮助下，侥幸降服了族中的荒破灭焱」 | 火焰掌控加强（现有异火系统接入） |
| 冰河谷 | 第1042章「冰河谷素来对于那些特殊的体质格外感兴趣」 | 对异常状态目标加伤 |
| 风雷阁 | 第394章「三千雷动…大陆风雷阁最高级的身法斗技」 | 身法/先手（已有技能，做宗门被动即可） |

## 4. 接入方案（以魂殿模板为准）

魂殿现有实现（可读源码，作为标准模板）：

```
config.py     DEVOUR_SECT="hundian" / DEVOUR_RATE=0.5
core.py       is_devour_sect(p)      → 判定
              devour_amount(exp)     → 纯函数算收益
              devour_of(p, mon)      → 战斗结算钩子（仅 boss/elite）
              fight() 内 +exp +pill_exp，回包带 devour
              change_faction() 内 is_devour_sect → 锁死转宗
```

每条新规则照此办理：

1. **单一真源**：在 `config.py` 加常量（`XXX_SECT` / 系数），不在多处写代码。
2. **纯函数**：在 `core.py` 加 `is_xxx_sect(p)` / `xxx_of(p, ctx)`，可单测。
3. **钩子**：只在 `fight()` / `alchemy_settle()` / `tower_settle()` 等结算点加一处调用。
4. **回包**：结果进 `res["xxx"]`，战报/卡片可见（用户要求「业务流畅」）。
5. **老档兼容**：新字段一律 `p.get(..., 默认值)`，老玩家不补数据也正常。
6. **禁止兜底**：规则失败显式报错/不生效，不静默给假加成。

### 4.1 推荐的最小落地点（P0 三条）

| 规则 | 常量 | 纯函数 | 钩子位置 |
|---|---|---|---|
| 古族族纹 | `GUZU_SECT`, `CLAN_TIER_STEPS` | `clan_tier(p)` → 血脉品级 | `stats()` 加成 |
| 丹塔丹会 | `DANTA_SECT`, `DANHUI_RANKS` | `danhui_rank(p)` → 名次 | `alchemy_settle()` |
| 蛇人封印 | `SHEREN_SECT`, `SEAL_RATE` | `seal_of(p, mon)` | `fight()` 结算 |

## 5. 平衡与风险

### 5.1 必须避开的坑（原著考据层面）

- **不可把个人所有写成门派传承**：厄难毒体属小医仙，不属毒宗；炎族几种异火分别属火炫/炎烬/火稚/火耀，是族人个人降服，不是「炎族传承之火」全部。这正是异火考据里已经踩过并修正的坑（19 派挂火 → 收敛到 11 派）。
- **不可编造原著无载的设定**：花宗原著记载稀薄（现有 sparse 标记正确），不要「补」不存在的独门绝学。

### 5.2 数值平衡

| 风险 | 缓解 |
|---|---|
| 新加成击穿 PVP/爬塔平衡 | 全部新增系数走 `config.py` 单一真源，可一键调 0 关闭；参照魂殿 `DEVOUR_RATE=0 合法` 的设计 |
| 根基惩罚口径被破坏 | 若新规则给修为（如丹塔丹会奖励），必须同步记 `pill_exp` 受 `root_factor` 约束，与魂殿同口径 |
| 转宗套利（刷规则加成） | 新规则若与等级绑定（族纹/血脉），转宗后按当前等级重算，不保留旧加成；或设冷却 |
| 老玩家不满（新号有加成老号没有） | 规则按 `lv` 派生，老号到等级自动享有，无需补数据 |

### 5.3 生产影响

- 当前 5 名玩家都在 starter/advanced，古族/太虚古龙等隐世规则对现网无人生效 → **先做隐世池规则风险最低**。
- 若做丹塔规则，现网有 1 名炼药师公会玩家（starter 池），需确认是否要覆盖到公会（原著丹塔与公会是不同组织，建议仅丹塔）。

## 6. 优先级建议

| 档 | 建议 | 理由 |
|---|---|---|
| **第一批（P0）** | 古族族纹 + 丹塔丹会 + 蛇人封印 | 原著证据最硬、系统接入最自然、辨识度最高 |
| **第二批（P1）** | 太虚古龙空间 + 毒宗仿毒体 + 天府联盟 | 需少量新机制，收益中等 |
| **第三批（P2）** | 炎族/冰河谷/风雷阁小额特色 | 锦上添花 |

**跨门派通用的一条**：25 派入门异火目前全相同（火云水炎），这是当初为防「超标火」做的收敛（见 `docs/门派异火归属_原著证据.md`）。若想增加差异，可考虑**用「门派信物/族纹」代替异火**作为宗门标识，不动异火平衡。
