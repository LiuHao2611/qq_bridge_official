## 1. 体验方法

- 黑盒纪律：只发玩家能在群里发的口令，只记录机器人回群的文字/卡片；不通过内部状态判断玩法是否正常。
- 存档隔离：在 import 游戏模块前设置 `DOUPO_DATA_PATH=/tmp/blackbox2/doupo.json`，玩家库、塔会话、周本会话、傀儡库、主题文件全部落在 `/tmp/blackbox2`，没有碰 QQ 20001 的旧存档，也没有碰本地 `src/plugins/doupo/data/` 或手机生产数据。
- 时钟推进：每天之间用模拟时钟推进，等价于玩家隔天上线；每条操作之间推进 30 秒，用于触发 CD / 60 秒选择窗口等真实等待。
- 覆盖基准：菜单卡 `shot_001.png` 底部写明「共 57 条口令」，按该卡六组逐条走完，并补了别名、子命令、后续操作和旧报告 P1~P8 的复验项。
- 已知限制：黑盒窗口里 `@某人` 是文本占位，不是真实 QQ at 对象，所以「抢 / 切磋 / 送」这类口令本轮只能验证到「是否回包 / 是否给用法」，不能据此判定真实 at 对战链路是否正常。

## 4. 本轮新发现问题

### N1 · 出塔状态没有真正清除（红，最高优先级）

- 第 2 天玩家发「出塔」，回包明确写：`你退出天焚炼气塔（本次 0 分钟，修为 +0）`，并写 `火毒 0/100`。
- 第 10 天玩家发「修炼」，回包却是：`你正在天焚炼气塔中心火淬体，此时静修是白费。发「入塔」结算塔修，或发「出塔」离开。`
- 补验：加载同一隔离存档后发「火能」，回包仍写 `状态：塔中修炼中`。
- 同一条「出塔」回包还写 `火毒未散，须歇一夜`，但火毒显示 `0/100`，自相矛盾。
- 影响：玩家按提示离开塔后，离线修炼被永久挡住，除非再发一次「出塔」；这是明确的玩家可感知功能错误。
- 证据：第 138-142、1286-1288 行；补验命令见第 7 节。

### N2 · 帮助与菜单承诺的「连炼 5 次」和实机回包不一致（红）

- 帮助卡放大图 `help_2.png` 写：`连炼：发「炼制 回灵丹 5次」一次开 5 炉，各炉独立成败，整批只占一次冷却`。
- 菜单卡放大图 `menu_3.png` 同样写：`「炼制 回灵丹 5次」连炼 5 炉，失败得药渣`。
- 玩家照做，第 6 天回包：`❌ 未能开炉：炉中火候难成——先看「炼药」丹方，再备齐药材与丹方。`
- 玩家先发单炉「炼制 回灵丹」，回包反而明确：`缺 紫叶兰×1(有0)`。
- 影响：文档承诺的功能写法在材料不足时给出错误原因，玩家会以为连炼功能坏了或自己没开火。
- 证据：第 714-726 行；`help_2.png`、`menu_3.png`。

### N3 · 新手引导说异火极稀有，但「收服 火云水炎」当场成功（橙）

- 第 1 天「入道」回包：`异火举世罕见，不会凭空而来——九星突破战胜强敌，或炼制兽火单方，方得一火。`
- 第 5 天玩家发「收服 火云水炎」，回包：`【火云水炎】认主`，没有九星突破、没有兽火单方、没有任何代价。
- 菜单卡写「数值火可直接收」，所以规则本身可能允许；问题是新手第一眼看到的引导与实际入口不一致。
- 证据：第 48、578-579 行；`menu_3.png`。

### N4 · 傀儡遗迹首次打开就显示「本次挑战 力竭」（橙）

- 玩家第 5 天首次发「傀儡遗迹」，卡片写 `今日进度 0/7`，但「本次挑战」区又写 `1 · 魔炎谷库房 力竭 | 1 回合 · 敌余血 14,296`。
- 玩家没有主动发挑战子命令，无法判断这是预览、历史残留还是刚才自动打了一场。
- 卡片第 2~7 层未解锁行文字与深紫底对比度过低，视力正常的新手也很难读清掉落与门槛。
- 证据：第 654-659 行；`shot_018.png`。

### N5 · 傀儡子命令没有差异化反馈（黄）

- `傀儡 淬炼 / 结阵 / 收服 / 融魂 / 换躯 / 养魂 / 出战` 七条命令全部回同一张「你尚未拥有傀儡」资格卡。
- 玩家无法判断命令是否被识别、子命令是否正确、自己离该子命令还差什么；只能看到通用开炉资格。
- 证据：第 1049-1172 行。

### N6 · 炼药连服在满血时无法验证数量差异（黄，低优先级记录）

- 「服丹 回灵丹」与「服丹 回灵丹 10」在满血状态下都回 `气血斗气都是满的`。
- 这不是明确 bug，但本轮没有覆盖到「受伤后一次服 10 颗」的真实效果；建议下一轮补一个受伤状态下的连服用例。
- 证据：第 729-744 行。

## 7. 机器复验命令

在仓库根目录执行：

```bash
# 重跑第二玩家全菜单体验（会清空 /tmp/blackbox2，重新从零入道）

```

回包统计（不依赖人工肉眼）：

```bash
python -c "import re; s=open('tmp/blackbox2_journal.md',encoding='utf-8').read(); t=chr(96); fence=t*3; cmds=re.findall(r'\*\*我发\*\*：'+t+'([^'+t+']*)'+t,s); reps=re.findall(r'\*\*群里回\*\*：\n\n'+fence+r'\n(.*?)\n'+fence,s,re.S); empty=[c for c,r in zip(cmds,reps) if '群里没有回应' in r or not r.strip()]; print('commands',len(cmds),'replies',len(reps),'empty',len(empty)); print(empty)"
```
