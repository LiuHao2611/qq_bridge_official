# 斗破·傀儡材料日副本「傀儡遗迹」· 设计方案（2026-11-18）

> 需求原话：「加一个每天都能打的新的副本，专门掉落傀儡材料 boss 和小怪，包括传承傀儡之技，
> 但是没想好副本背景应该怎么结合原著设计才有新意和好的玩法。」
>
> 本文只做**设计**，不改代码。是 `斗破傀儡系统_设计方案_2026-11-18.md`（从零重写版）的配套篇：
> 那篇定义「傀儡需要什么」，这篇定义「这些东西从哪里打出来」。
> 考据统一以 `斗破傀儡_原文证据台账_2026-11-18.md` 的 E 编号为准；本文出处括号里的章节标题
> 与台账一致，硬条件如与台账冲突以台账为准。
> 所有数字标注 `[调参]`；原著场景用章节标题定位（转载站多卷制章号会重置）。

## 〇、一句话结论

不要造一个凭空的「傀儡洞窟」。原著里**现成有一条完整的傀儡因果链**：
**魔炎谷**（天妖傀竹简的抄家来源 + 地魔老鬼的尸身/铁护法的魂）
→ **天墓**（远古能量体 + 十具守护地妖傀，原著就有「傀儡守遗迹」的成熟桥段）
→ **虚空雷池**（雷霆淬炼提纯，原著明确「吞噬黑魔雷」升天妖傀）。
把这三处做成副本的三段，每段掉一样傀儡前置材料，**背景、怪物、掉落、玩法四者同源**，
既有原著名场面撑腰，又天然把「传承/躯体/灵魂/魔核/金属/雷材料」全覆盖。

## 一、考据边界（哪些是原著、哪些是游戏设计）

| 场景 | 原著确认的事实（出处） | 游戏化处理 |
|---|---|---|
| **魔炎谷** | 黑角域老牌势力，萧炎联合迦南院将其「抄家」，从库房得「天妖傀」竹简（`第九百章养魂涎`）；地魔老鬼七星斗宗尸身、魂殿铁护法灵魂都出自这条线（`第九百零四~九百零六章`） | 完全忠于原著：库房=传承掉落点，谷主/护法=躯体与灵魂来源 |
| **天墓** | 古族禁地，埋葬无数远古强者，其能量化作的「能量体」会生前斗技、分三层（斗尊以下→斗尊→斗尊巅峰/斗圣）（`第一千三百一十章天墓开启`）；**十具地妖傀守石门，靠阵法可合体进化天妖傀**（`第一千两百二十一章收服`）；内有「天墓之魂」奴役能量体互相吞噬（`第一千五百七十四章天墓之魂`） | 借「傀儡守遗迹」桥段做 Boss；三层结构做难度递进；「天墓之魂」做机制型 Boss（见 §3.2） |
| **虚空雷池** | 雷霆聚集的凶险之地，「湖」由纯雷霆构成，越深越恐怖；天妖傀在此修复+强化，北王在此吞噬黑魔雷进阶（`第一千两百十六章虚空雷池`、`第一千五百三十一章吞噬黑魔雷`） | **注意**：原著是「淬炼圣地」不是战场，故第 3 段做成「护法/抢池」玩法而非纯刷怪（见 §3.3） |
| 副本「每天一次」 | 原著无此设定 | 纯游戏化节奏设计，明确标注，不冒充原著 |

⚠️ 三条不许写进文案的误传：① 原著没有「傀儡副本」这个名词；② 天墓能量体不是野怪、是死者能量残留；
③ 虚空雷池不是打怪掉宝地，是淬炼地。文案只说「进入遗迹 / 淬炼」，不说「原著里的副本地牢」。

## 二、副本总览

- **名字**：傀儡遗迹（三段：魔炎谷库房 / 天墓·能量之层 / 虚空雷池）
- **节奏**：每日一次完整挑战窗口（日期切换重置，用 `date.today()` 判定，不靠在线时长）
- **入口**：新口令 `傀儡遗迹`（出图，展示三段进度与当日状态）。
  **先过配套篇 §3.5 五道资格**（境界 lv / 灵魂境界←炼药等级 / 控火←炼药功底 / 异火 / 斗气续航，
  详见台账 E22-E31，均挂已有系统）——未开通者进不去，并明确提示"先修炼到对应境界/提升炼药品阶/多炼药/收服异火"；
  境界下限按目标档次：人级≥斗师、地级≥斗宗、天级≥斗尊 `[调参]`。避免玩家攒了材料却发现没资格炼制。
  注意：灵魂与控火是**炼药练出来的**，副本里掉不了（副本只掉傀儡材料）；
  **异火例外**——异火本来就是宗门传承或精英怪/Boss 掉落所得，可由副本的精英/Boss 产出。
- **难度**：按玩家画像 `monster_scaled` 反解（复用周副本的 `weekly_snapshot` 思路），
  但取**当日快照**而非周一快照——日副本每天重置，用当日画像即可，避免跨天难度错位。
- **失败处理**：与周副本「一命到底清空」不同（那是用户明确要的高压玩法），
  日副本采用**分段保留**：过了哪段就保住哪段掉落，死了从该段重开。理由见 §五决策。
- **掉落直连**（关键设计）：每段的 Boss/小怪掉落**恰好对应傀儡的一条前置材料**，
  打完三段=凑齐一次炼制（传承除外，传承仅首通给，见 §3.1）。

## 三、三段设计（背景 / 怪物 / 掉落 / 玩法）

### 3.1 第一段 · 魔炎谷库房 —— 传承、躯体、灵魂

**背景**：萧炎抄家后的魔炎谷库房，谷中残党与凶魂仍在把守。原著里天妖傀竹简正是
从这处库房所得，地魔老鬼的尸身、铁护法的灵魂也是这条线的产出，完全同源。

- **小怪**：谷中护卫（黑角域斗者/斗师）→ 掉「躯体材料」残件；凶魂残念 → 掉「无神智灵魂」碎片。
- **Boss**：地魔老鬼（七星斗宗尸身）→ 首通必掉**天妖傀竹简**（`puppet_lore=True`），
  复通掉高纯度躯体材料（带境界/星级，供 `puppet.body`）。
  🆕 **躯体带保鲜期**（`fresh_until`）：原著两具尸身都是「被冰封的尸体」，
  故掉落的躯体材料有时效，过期腐烂则不可入料（配套篇 §3.7 步骤〇）——
  这也给"当天打、尽快用"一个原著依据，避免材料无限囤积。
- **新意（玩法）**：**「尸身完好度」机制**。战斗中加入 1~2 次「补刀时机」判定——
  原著炼傀儡要求躯体尽量完整（尸气可驱、躯壳不能烂）。玩家若在 Boss 残血时
  用特定手段（如控制技/低伤害收尾）完成击杀，躯体掉落档次 +1；否则只掉普通档。
  这把「战斗表现」与「炼制材料品质」挂钩，比单纯掷骰子掉宝有参与感。
- **对应前置**：传承（竹简）、躯体（`body`）、灵魂（`soul`，已去神智）。

### 3.2 第二段 · 天墓·能量之层 —— 魔核、特殊金属

**背景**：古族天墓，远古强者的能量体在此游荡；十具地妖傀守着石门，
原著中它们能靠阵法合体进化成天妖傀——这是「傀儡守遗迹」最正的原型。

- **小怪**：远古能量体（分三层，对应斗尊以下/斗尊/斗尊巅峰），掉各阶魔核
  （带属性，供 `puppet.core`）。
- **Boss**：守护地妖傀（十具）→ 掉特殊金属（暗金玄铁等，供 `puppet.metal`）。
- **新意（玩法 A · 阵法合体）**：Boss 战复刻原著——十具地妖傀血量降到阈值时
  「结成循环阵」，合体进化为天妖傀（一回合强攻）。玩家要**先破阵眼**（打掉某一具
  带标记的傀儡）才能阻止合体，否则更难。这是把原著桥段直接变成战斗机制。
- **新意（玩法 B · 天墓之魂的吞噬令）**：原著「天墓之魂」给能量体种下互相吞噬的诅咒。
  做成负面 buff：小怪之间会「吞噬合并」——若玩家拖太久，两只小怪会合成更强的
  一只（血/攻叠加但数量减少），逼玩家快速清场。这是有原著根据的紧迫感，
  不是凭空加计时器。
- **对应前置**：魔核（`core`）、特殊金属（`metal`，决定皮肤金银铜）。

### 3.3 第三段 · 虚空雷池 —— 雷材料、淬炼进度

**背景**：纯雷霆构成的凶险之地，原著是天妖傀修复强化、北王吞噬黑魔雷的淬炼圣地。
**正因为它是淬炼地而非战场，这里不做「打池子」，而做「护法抢池」。**

- **玩法**：玩家把已炼成的傀儡（或本段产出的傀儡胚胎）送入雷池淬炼，
  期间雷霆能量乱流来袭——玩家要**护住雷池中的傀儡**若干回合（类比护送/守卫）。
  原著里萧炎敢独闯是靠异火护体，所以**持有异火者受击减免**（与 §3.5 控火/异火门槛呼应）。
- **小怪**：雷霆能量乱流 → 掉雷系材料。
- **Boss**：黑魔雷（原著中北王吞噬进阶的关键，E41）→ 掉大额「雷池淬炼进度」，
  可直接推进 `puppet.purity`。**按配套篇 E06/E07/E08 的两级台阶**：首炼恒人级铜，
  雷淬进度达标后 人级铜→地级银→天级金，天级封顶。
- **对应前置/培养**：雷系材料与淬炼进度（对应傀儡系统的「雷池淬炼」培养线），
  以及成品进阶。这段是唯一「先有傀儡才收益最大」的段，形成养成闭环。

## 四、掉落与傀儡前置的对应表（设计自检：没有一样是凭空掉）

| 傀儡前置（见配套篇） | 副本来源 | 段 |
|---|---|---|
| 传承（天妖傀竹简） | 地魔老鬼 Boss 首通 | 一 |
| 躯体（带境界/星级） | 谷中护卫 + 地魔老鬼，受「尸身完好度」影响 | 一 |
| 灵魂（已去神智） | 凶魂残念 | 一 |
| 魔核（带属性/阶数） | 天墓能量体（按层分阶） | 二 |
| 特殊金属（定皮肤金银铜） | 守护地妖傀 Boss | 二 |
| 火候/控火 | **不掉**（能力门槛，靠修炼五轮离火法，见配套篇 §3.5） | — |
| 雷系材料 / 淬炼进度 | 雷池乱流 + 黑魔雷 Boss | 三 |

> 火候/控火刻意**不设为掉落**——它是使用者本事，不是材料；掉了就违背原著「靠自己修成」。

## 五、玩法机制与决策

| 设计点 | 选择 | 理由 |
|---|---|---|
| 每日次数 | 1 次完整窗口，日期切换重置 | 「每天都能打」的直译；避免无限刷破坏材料价值 |
| 难度口径 | 当日玩家画像反解，三段递进 | 复用 `monster_scaled` + `weekly_snapshot` 范式，不引入新平衡公式 |
| 失败处理 | 分段保留（过段保掉落） | 与周副本「一命清空」拉开差异：那是高压挑战，这是稳定养成来源；日副本要鼓励每天都打 |
| 传承掉落 | 仅首通给，复通不再给 | 传承是「学会」不是「消耗品」；复通改掉高纯材料 |
| 尸身完好度 / 破阵 / 护池 | 三个原创小机制，均有原著根据 | 提供「操作影响收益」的参与感，不是纯掷骰 |
| 异火减伤（雷池段） | 有异火则受击减免 | 呼应原著「异火护体才敢闯雷池」，把能力门槛做成玩法优势 |

## 七、风险与待定

- **待定**：副本难度是否允许傀儡参战？若允许，需与配套篇 §3.2/§3.3 的反解口径一致
  （傀儡输出计入 `damage_schedule`，且结阵增益 §3.7 同样计入）；若不允许，要在入口显式说明
  「遗迹中不得携傀儡」，否则玩家会带着傀儡碾压、材料来得太易。建议**允许但计入反解**，保持口径统一。
- **考据诚实**：「尸身完好度」「破阵眼」「护池」三个机制是**游戏原创玩法**，
  只是取材原著桥段，文案不得写成「原著设定」。
- **材料通胀**：日副本 + 每日一次，要核对掉落率使「凑齐一具傀儡」约需 N 天 `[调参]`，
  避免第一天就全身天妖傀，把养成线打穿。
