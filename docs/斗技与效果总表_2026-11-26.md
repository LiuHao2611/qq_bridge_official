## 二、规则口径

### 2.1 三阶基线

| 阶 | 基础倍率 | 斗气占比（斗之气档） | 解锁 | 说明 |
|---|---|---|---|---|
| 普通 | 100% | 20% · 气海 | lv1 | 黄/玄阶，斗技堂与各宗基础技 |
| 高阶 | 140% | 34% · 气海 | lv20 | 地/天阶，宗门核心传承 |
| 特殊 | 180% | 50% · 气海 | lv40 | 秘法 / 异火技 |

实际倍率 = **阶基础倍率 ×（1 + 0.2 ×（技能等级 − 1））**，升级每级 +20%，最高 5 级（材料：焚血散）。

### 2.2 斗气消耗随境界递减（2026-11-26 起）

同一门斗技，境界越高占比越低 —— 练级涨的斗气上限才有实感（每战能放的次数随修为增长，战斗回合数不变）。

### 2.3 释放规则

* 上阵 **4 槽**，三阶任意搭配（后期可以 4 特殊）；
* 每回合在「已上阵 + 斗气够 + 冷却已好」的技里**随机释放**一门；
* 一个都放不出 → 武器普攻（不空过回合）；
* 斗气跨战结转、不回满，所以高境界能连打更多场。

## 三、效果一览

### 3.1 效果原子（每门斗技的 `effects` 由这些代号组成）

| 代号 | 名称 | 作用 |
|---|---|---|
| `dot` | 持续伤害 | 每回合按伤害比例持续掉血（子类：血毒 / 流血 / 灼烧 / 中毒） |
| `lifesteal` | 吸血 | 打出伤害的一部分回补自身气血 |
| `pierce` | 破防 | 无视目标一部分防御 |
| `debuff_atk` | 降攻 | 降低目标攻击，持续若干回合 |
| `debuff_evade` | 压闪避 | 压低目标闪避，越打越躲不开 |
| `debuff_heal` | 减疗 | 削减目标受疗效果（克回血） |
| `stun` | 眩晕 | 目标该回合无法出手 |
| `silence` | 禁技 | 只能普攻，放不出斗技 |
| `root` | 定身 | 无法位移 / 脱离 |
| `knockback` | 击退 | 打断对方节奏，拉开距离 |
| `reflect` | 反伤 | 把受到的一部分伤害弹回对手 |
| `reduce` | 减伤 | 自身受到的伤害按比例降低 |
| `evade` | 闪避 | 提高躲避判定 |
| `chain` | 连击 | 同一回合追加段数 |
| `cond` | 条件加伤 | 满足条件（恐惧/守势/火势/位移后/残血）时额外增伤 |
| `empower` | 增幅 | 自身攻击等属性按比例提升 |

### 3.2 条件加伤（`cond` 的触发条件）

| 代号 | 中文 |
|---|---|
| `fear` | 恐惧 |
| `defensive` | 守势 |
| `fire` | 火势 |
| `after_move` | 位移后 |
| `low_hp` | 残血 |

### 3.3 主定位（`role`）

　输出　·　爆发　·　续航　·　控场　·　异常　·　防御　·　位移　·　功能

### 3.4 持续伤害子类

　血毒　·　流血　·　灼烧　·　中毒
