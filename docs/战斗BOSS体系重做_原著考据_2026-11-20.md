## 铁律（先立后做）

1. **台词必须有原文出处**：每条 BOSS 台词标注章节号 + 原文引文。语料里没说的话**绝不代编**，
   宁可只用原文出现过的短句。全文已由子代理逐字交叉核对，未命中语料的一律不进卡面。
2. **不写"快照玩法"**：删掉 `make_breakthrough_boss` 的"战力快照反解"和文案里的
   "快照战力 XXXX"。改成**原著有名有姓的 BOSS**，用普通怪同一套 `monster_scaled`
   按等级缩放（保留数值平衡），难度来自该 BOSS 的 hard 系数 + 机制，而不是"打自己的镜像"。
3. **终局一个数**：沿用 `core.record_last_battle` / `fight()` 的 `hp_end` 单一真值口径，
   本轮不动数值层。
4. **机制复用现成效果系统**：`skill_effects.py` 已有 silence/stun/reflect/debuff_heal/
   debuff_atk/dot/def_shred，"恶心机制"优先挂在这些类型上，不另造轮子。

## §3 数据结构（config 新增，纯字面量）

```python
#: 每个 BOSS/精英怪的"角色包"：登场引言 + 台词 + 技能 + 机制。
#: quote 全部来自 §2 已核对原文；intro 为原文场景的引用式转述，标 source。
BOSS_CHARACTERS = {
  "魂殿摘星老鬼": {
    "title": "魂殿天尊",
    "source": "第一千一百九十九章 摘星老鬼",
    "intro": "既然老夫已经露面，怎还能让你们安然离去？",
    "quotes": [
      "在绝对的实力面前，这些都没有用",
      "凭借斗宗实力，便敢戏耍老夫，这可是老夫遇见的头一次！",
      "九幽魂手！",
    ],
    "skill": {"name": "九幽魂手", "chance": 0.28, "effect": "drain", "mult": 0.12},
    "mechanic": {"type": "silence", "d": 1, "chance": 0.25,
                 "desc": "黑雾锁魂——下一回合斗技被封，只能以尺肉搏"},
  },
  # ... 其余 11 个 + 精英怪，待台词核对完成后逐一填齐
}
```

- `intro`：**登场时插一条无伤害旁白 log**，沉浸式"突如其来的惊喜/惊吓"由它承载。
- `quotes`：技能施放时按 notes 带出；战败/胜利各有专属收尾台词。
- `mechanic`：复用 `skill_effects` 的 effect type；精英怪"一个技能 + 一个恶心机制"。

## §4 战斗日志接入点（core.fight）

- 战斗开始（`roll_hero_aid` 之前）插入 1 条 `{"kind": "登场", "speaker": name,
  "quote": intro, "dmg": 0}`；`_mark` 会给它补 round/foe/hp_after 字段。
- 怪物技能命中时，若该怪有 `quotes`，把台词并入 notes 的 `monster_quote` 字段
  （不改 kind/dmg，沿用已核对过的"技能并入 notes"口径，避免回看卡把一次攻击拆两行）。
- 机制在怪物出手那一次走 `fx.on_hit(effects, m_fx, p_fx, ...)`，挂到玩家身上；
  效果生效由 notes 呈现，数值仍由现有 system 结算。
- 逞强/失误/心火共鸣等既有条目不动。

## §5 结算展示重排

用户："结算展示也乱七八糟的"。现状 `cmd_fight` 的 5 行骨架 + 条件 `insert` 会打乱行序。
重排为固定三段、顺序恒定：

```
⚔️ 遭遇 N 敌 · R 回合 · {大捷/力竭}
【战果】斩获 X ｜ 修为 +Y ｜ 金币 +Z
【代价】受伤 T ｜ 余血 H ｜ 服药 n
【机缘】（仅触发时出现，恒定排在最后）贵人相助 / 心火共鸣 / 战利 / 突破提示
```

突破战结算单独走 `cmd_break`，增加"BOSS 登场引言 → 鏖战 → 台词收尾 → 突破结果"的
沉浸式四段，删掉所有"快照战力"字样。

### §7.1 野外 / 塔 / 周本角色包口径（补做「每一个精英怪和 BOOS」）

- 数据：`config.MONSTER_CHARACTERS`，键为怪物名；塔精英层的「精英·X」由
  `monster_character()` 剥前缀复用同一角色包。
- 接入：`monster_scaled()` 自动挂 `character`，技能优先级
  **species 自带 > 角色包专属 > MONSTER_SKILLS > kind 兜底**；塔 BOSS 因此用
  「血刀」「魂魔手」而非通用「魂殿秘技」。数值仍只由等级/层号反解，角色包不进面板。
- 精英/BOSS 必有 `skill` + `mech` + `intro`；普通怪 `intro=""`，避免一场 5 连战刷 5 条旁白。
- 诚实边界：
  * 「天毒蝎龙兽」两句台词逐字出自语料第 4171 行；「摘星手！」「黑盟不会放过你们的！」
    亦逐字命中。
  * 「游戏原创」怪（塔灵/塔卫/黑盟死士/魂殿执事/云岚山守山兽/天山雪蟒等）
    `source` 明写游戏原创，`quotes=()`，不冒充原著台词。
  * 语料只作「翼黑蛇皇」，已把旧表「八翼黑蛇皇」全部改正。
  * 血刀圣者/魂魔老人/狮天/天蛇老怪/蝎山/范痨的人名经逐字核对，但**无可归属本人的
    可靠台词**，一律 `quotes=()`，只用场景旁白。
- 守门：`tests/test_doupo_boss_cast.py` 45/45；反证 M7~M11 均报红。

### §7.2 卡面为何看不到机制（踩坑留痕）

`battle_review.action_items` 原先 `notes[:2]`，模板标签行又 `_fit` 成单行；第三条
「九幽·锁魂（空间崩塌）！」被静默吞掉。修法：数据层放开到 `TAG_LIMIT`，渲染层
`S.wrap_cjk` 按列宽折行 + `BUBBLE_TAG_H * len(tag_lines)` 重算气泡高，绘制与度量同源。
反证 M9 把上限改回 2 必红。
