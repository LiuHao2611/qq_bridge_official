## 三、版式口径（度量优先）

- 描述字号 `REALM_DESC_FS = FS_SMALL = 18`，弱色 `p["dim_color"]`，不加粗。
- 行高 `REALM_DESC_LH = FS_SMALL + 8 = 26`；描述块与修为条之间 `REALM_DESC_GAP = 8`。
- 「境界修为」标签基线 `y+11`，描述块从 `y+30` 起画；实测浅色主题下标签→描述净间隙 9px、描述→修为条 16px。
- 折行入口只有 `_realm_desc_lines()`，`_measure()` 与 `build()` 都消费它；窄屏 560 时 2 行，卡片高度随行数增加，不靠估算。
- `boxes=...` 是可选参数，默认 None 零开销；只在自检时登记境界区块，不改变正常渲染路径。
