## 0. 一句话结论

近三年真正能直接搬进战斗文本的，不是长句金句，而是**「短、有节奏、自带画面、能当反转音效」**的四类：

1. **登场仪式类**：「啊，是关中王来了」「既见未来，为何不拜？」
2. **放招/救援类**：「炸火花，破！」「助我破鼎」「我来助你」「广智救我」
3. **濒死/自嘲类**：「告诉俺娘俺不是孬种」「活人微死」「今日缓冲，明日再战」
4. **嘲讽/阴阳类**：「我要验牌」「你的胆子真是肥嘟嘟的啊」「我并不知道您到底是怎么了」

这四类的共同点：单独成句就能立住，不需要解释梗源，放进战报里不会显得「文案在掉书袋」。

## 4. 落地建议与边界 `[推断 / 注意]`

1. **只用短句，不整段照抄影视台词。** 上表多数是影视/游戏台词，直接整段搬进游戏属于版权敏感区；短句玩梗属于网络文化引用，风险低得多。真要进产品，建议改写为「同节奏的自有句」（例：「既见未来，为何不拜」→「既见斗宗，何不躬身」）。
2. **别把年份、平台、品牌名写进战报。** 「抖音大学」「蔚来」「袋鼠」「帕鲁」这类词一出现就出戏，除非刻意做跨次元彩蛋。
3. **优先挑「不需要解释」的。** 「关中王来了」「我来助你」「炸火花，破」「我要验牌」是即使没看过原片也能被节奏带住的；「样人笑幻」「嘉豪」「我 chovy」高度依赖语音/画面，纯文本会失效。
4. **注意攻击性分级**：1.2/1.3/1.6 安全；1.5 的「你就是朱之文」「鸣潮公式」带阴阳/争议属性，建议只给 NPC 对白，别写进玩家胜利回包。
5. **时效性**：2026 上半年梗到年底已有衰减，做常驻文案优先选 2024–2025 的年度级梗；2026 新梗适合做限时活动/节日彩蛋。
6. **别做「梗百科式注释」。** 玩家在游戏里看到「本梗出自……」会立刻出戏——这是之前用户反复纠正过的沉浸红线。
