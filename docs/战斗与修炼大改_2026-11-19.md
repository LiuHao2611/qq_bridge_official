## 一、原著考据（带章节，全部逐字核对过）

### 1.1 「萧炎走之后的天焚炼气塔」到底是什么样

**塔失去心炎后的冷清状态**——「第百七十二章 再进塔底」：

> "如今的天焚炼气塔由于心炎的枯竭，因此也是丧失了那种人来人往的人气，
> 喏大的空间，唯有寥寥身影存在……"
> "不管如何，天焚炼气塔之内的火属性能量总是要比外界强盛许多，
> 毕竟其地底那庞大的岩浆世界，可是不断的弥漫出雄浑的火属性能量……"

**萧炎留下的永久方案 = 聚火壶 + 幼生体陨落心炎**——「第百五十章 一劳永逸」：

> "这东西是迦南院一位守阁老先生所造，他将之称为'聚火壶'，
> 只要你能够将一丝真正的本源陨落心炎注入其中，日后，再由人不断的在其中注入斗气，
> 便是能将激活，并且源源不断的产生心火，当然，这种心火的效果自然是比不上
> 当年陨落心炎本体所造那般超强效果，但也依旧有着一些修炼增幅的效果。"

「第百十三章 情报」进一步改为幼生体：

> "如今的它尚还处于幼生期，但只要内院有着修习火属性功法的长老源源不断的
> 为其灌注斗气，它所提供的心火，依旧能够令得天焚炼气塔再次焕发作用……
> 天焚炼气塔，或许可以永久开启了"

「第百十四章 商议」是塔重新激活的完整流程：

> "四股色泽深浅不一的火属性斗气……皆是尽数冲进其中那朵陨落心炎之中……
> 一圈圈无形的波动，迅速从聚火壶之中扩散而出……最后一层层的穿透塔层，
> 将整个天焚炼气塔，都是包裹在其中。"
> "看来日后就是要麻烦我们内院那些修行火属性斗气的长老了啊……
> 日后你们或许就得轮班换着来了，呵呵，就当是修炼吧，有消耗才有增涨。"
> "有了心火淬炼体内斗气，他们的修炼速度，起码能够成倍翻长。"

**结论（本作要还原的四个机制）**：

1. 心火不是免费白来的：**需要持续灌注斗气维持**（长老轮班 = 长期饭票）
2. 效果比本体弱，但**成倍翻长**修炼速度
3. 心火是**全塔范围**的 buff，不是单人独占
4. 塔底层封锁、地底岩浆世界持续渗出火属性能量 —— 后期是「遗迹 + 火属性宝地」

### 1.2 火晶卡与火能（早期制度，后期未再提收费，故本作只取「分层代价」的设计精神）

「第百五十七章 奖励」：

> "火晶卡由低到高，分为黑，蓝，青，赤，紫五种颜色……
> 黑色晶卡……只具备在'天焚炼气塔'第一二层修炼的资格，
> 而蓝色晶卡，则是三四层，如此例行推下。"
> "从黑色晶卡调换成蓝色晶卡，需要缴纳一百天'火能'"

「第四百十六章 闭关」：

> "每下一层，所需要的火能便是要增加一天……这第三层修炼一天，便是需要'三天'的火能"

「第百二十四章 塔中暴动 / 第五百二十三章 一号修炼室」：

> "这一号修炼室……在这里修炼一天，似乎是要扣取三十天火能吧。"
> "若说在前几层修炼时，所产生的心火是一丝一缕的话，那么在这一号修炼室，
> 心火则是以成团成团的方式出现。"

⚠️ 注意：语料中**没有「火晶石」**这个词，只有火晶卡与火能。
后期章节（一劳永逸/情报/商议）**未再提收费**，不能据早期制度断言后期仍收费。
本作采用折中：火能 = 维持心火的「灌注斗气」凭证（与后期设定一致），分层消耗（取早期精神）。

### 1.3 火毒与作息（本作要做成硬约束）

「第四百七十四章 中级修炼室」：

> "心火淬炼……在将斗气中的杂物淬炼之时，也是会有着一丝火焰狂暴之力掺杂而进……
> 这种火焰狂暴之力，并不能用斗气化解，而必须用时间磨合，
> 所以……最好修炼半天，再休息一夜，这般作息，最好。"
> "如果晋入了斗灵级别，则是能够在塔中一次性修炼四五天而不用出塔"

「第四百七十六章 第二层」：

> "不管新生实力有多强，都必须在第一层坚持修炼一周时间……
> 那心火炙烤，不管实力如何，总是会在斗气之中掺杂上一丝火毒……
> 内院这么多年中，因为火毒累积而对造成难以挽回损失的人，可并不少啊。"

**结论**：火毒是真实代价；斗灵（本作 lv37）是能否连修的分水岭。

## 二、战斗系统改造

### 2.1 取消回合上限（但保留异常熔断）

* 删除 `fight()` 的 `rounds < 15`。玩家普攻与怪击都至少 1 点伤害 → 数学上有限回合必分胜负。
* 保留 `HARD_ROUND_CAP = 300` **仅作死循环熔断**（不是玩法上限）：达到时按剩余血量比例判定胜负，
  战报写明「久战力竭」，绝不静默判负。
* `duel()` 的 `rounds < 15` 同步去掉（同一口径，PVP 不许另留天花板）。
* `test_core.py::test_fight_always_terminates` 从「15 回合内结束」改成「有限回合内必结束 + 熔断可达」。

### 2.2 自动服药（只认未锁定物品）

* 触发：战斗中我方气血 < `AUTO_PILL_HP_RATIO=0.35`、斗气 < `AUTO_PILL_MP_RATIO=0.20`。
* 每场各自最多 `AUTO_PILL_MAX_PER_FIGHT=2` 枚（防止一场嗑光家底）。
* 候选：背包中所有 `effect=hp/mp` 的丹药 + 天材地宝，**排除锁定表里的名字**；
  按「恢复量从小到大」取（先省钱药，高级药留给真正硬仗）。
* 每回合怪击之后判定一次；服药写一条 `log`（`kind="服药"`，带药名与实际恢复量），
  真正 `take_item` 扣背包。
* `fight()` 新增 `auto_pill=True` 参数；爬塔/周本用深副本战斗，传 `False`
  （它们有专属三选一补给，不能消耗真实背包）。

### 2.3 背包锁定（新数据必须真实列）

* 新表：`item_lock(qq TEXT, name TEXT, locked_at REAL, PRIMARY KEY(qq,name))`。
* `Store.item_locks(qq) -> set[str]`、`Store.set_item_lock(qq, name, locked)`。
* 新增口令 2 条：`锁定 <物品名>` / `解锁 <物品名>`（菜单 45 → 47）。
* 语义：锁定只阻止**自动使用**；手动「使用 <物品>」仍可服用（用户原话只说自动）。
* 卡面/文本包裹已锁物品加 `🔒` 前缀。

### 2.4 每怪一技能（概率施放）

`cfg.MONSTER_SKILLS` 按怪名定义 `{name, chance, effect, mult, desc}`，23 只全覆盖。
三种效果口径（复用现有战斗字段，不新增 effect 类型）：

* `burst`：本次怪击伤害 ×1.4（蓄力猛击）
* `poison`：附加每回合 DoT，持续 2 回合
* `drain`：造成伤害同时抽走玩家斗气（按上限 8%）

`monster_scaled()` 透传 `skill` 字段到怪物实例；`fight()` 在怪反击掷骰，
命中则施放并在战报 log 标 `monster_skill` + `kind=技能名`。
概率：普通 0.12~0.18，精英 0.22，Boss 0.28（`BOSS_KIND_TOKENS` 识别）。

### 2.5 战斗意外（丰富过程，不改数值内核）

* 怪物失误：`MISHAP_CHANCE=0.08`，怪回合掷中 → 本回合不攻击，
  文案按 kind 选「脚掌一崴，一屁股坐在地上」（魔兽）/「手忙脚乱，自乱阵脚」（人型反派）。
* 玩家福利：`FORTUNE_CHANCE=0.04`，每场最多 1 次，持续 `1~2` 回合：
  玩家伤害 ×1.3、承伤 ×0.7，log 标「心火共鸣，气机顺畅」。
* 全部通过 `fight` 内的局部变量实现，**不改 stats/人物卡/掉落**，
  战报新增 `event` 字段供回看卡渲染。

## 三、修炼大改：后期天焚炼气塔（聚火壶）

### 3.1 玩家可达的「塔」是什么

不是早期那种「交火能进修炼室」，而是：

> 萧炎留下幼生体陨落心炎在聚火壶里 → 内院长老轮班灌注斗气 → 心火波动覆盖全塔 → 塔中修炼者成倍变强

本作映射：

* **聚火壶**：玩家持有的「幼生心炎」等级（靠灌注斗气成长）
* **火能**：灌注斗气的凭证（战斗胜利获得 + 每日免费补充）
* **火晶卡**：黑/蓝/青/赤/紫五档，决定可进入的层数与心火倍率
* **心火倍率**：黑 1.5 / 蓝 2.0 / 青 2.8 / 赤 4.0 / 紫 6.0（"成倍翻长"）
* **火毒**：心火淬炼的代价，累积到 100 必须出塔冷却；斗灵（lv37+）累积速度减半
* **塔底岩浆世界**：紫卡 + lv37+ 解锁，额外 1.5× 收益、火毒也 1.5×

### 3.2 数据与命令

新表（真实列，不进 `players.data`）：

```sql
CREATE TABLE IF NOT EXISTS alchemy_tower (
    qq          TEXT PRIMARY KEY,
    card_tier   INTEGER NOT NULL DEFAULT 0,   -- 0黑 1蓝 2青 3赤 4紫
    fire_energy INTEGER NOT NULL DEFAULT 0,   -- 火能（天）
    fire_poison INTEGER NOT NULL DEFAULT 0,   -- 火毒 0~100
    last_ts     REAL    NOT NULL DEFAULT 0,   -- 上次塔修结算时刻
    free_day    TEXT    NOT NULL DEFAULT '',  -- 每日免费领取日
    enters      INTEGER NOT NULL DEFAULT 0    -- 累计入塔次数
);
```

新增口令 3 条（菜单 47 → 50）：

* `入塔`：结算塔修（离上次结算以来的分钟 × 倍率 × 异火加成），扣火能、加火毒
* `火能`：查看聚火壶状态（卡色/层数/火能/火毒/倍率/岩浆世界解锁）
* `换卡`：升一档火晶卡（100/200/400/800 火能，对应原著「缴纳火能换卡」）

`修炼`（被动静修）保留不变，文案加一句「入塔可借心火成倍修炼」。

### 3.3 火能来源

* 战斗胜利：`+ max(1, mon.lv // 5)` 火能（原著「战斗中夺取火能」）
* 每日免费：`+20` 火能（原著「内院每月组织免费入塔」的游戏化每日版）
* 不出售（不涉及经济系统改造）
