## §0 一页速览：为什么"感觉"技能概率低

先给结论——**配置里的概率不是最终值，实际有三层修正**，用户看到的"低"主要来自第 3 层：

| 层 | 机制 | 影响 |
|---|---|---|
| ① 基础值 | 每个怪技能自带 `chance`（0.15~0.34） | 写在配置表里的数 |
| ② 档位加成 | BOSS ×2.0 / 精英 ×1.5 / 普通 ×1.0 | **实际施放概率已在 0.30~0.68**，并不低 |
| ③ 二次判定 | 命中后 `mech` 恶心机制再乘一次 `p`（0.22~0.35） | 禁技/反伤/中毒这类"有感觉"的机制只有 **13%~24%** |

所以：
- **技能本体**（爆发/夺气/中毒那一下）施放概率其实不低，BOSS 普遍 40%~68%；
- **真正让玩家觉得"没放技能"的**，是带 `mech` 的控制类效果（禁技、反伤、封脉）经过了第二次掷骰，概率被打到 1/4 左右；
- 另外**技能是每回合掷一次**，一场战斗 1~5 个敌人、每个敌人各打若干回合，单回合 15% 累积起来并不算稀有；但短战斗（1-2 回合秒掉）确实容易一场都碰不到。

⚠️ 还有一条硬规则：**玩家挂了「禁技」时，怪当回合完全不判定技能**（`core.py:1670`），这是玩家斗技的正常收益，不是 bug。

## §1 施放概率计算口径（唯一真源）

```
实际施放概率 = min(1.0, chance × 档位系数)
  档位系数：BOSS = 2.0 ；精英 = 1.5 ；普通 = 1.0
档位判定 = core.mon_tier(kind)：
  BOSS  → kind 含 魂殿/黑盟/魔炎谷/boss/BOSS，或 is_boss=True
  精英  → kind 含 elite/精英（塔·elite / 周本·elite）
  普通  → 其余（魔兽/悍匪/塔·normal…）

恶心机制实际触发 = 实际施放概率 × mech.p   （技能命中后再掷一次）
```

- 基础兜底 `MONSTER_SKILL_BASE_CHANCE = 0.15`（技能条目缺 chance 时用）。
- 技能来源优先级（`core.py:969`）：**species 自带 > 角色包专属 > 野外技能表 > kind 兜底**。
- 效果三类：`burst`=本次伤害×mult；`drain`=抽玩家斗气；`poison`=挂 2 回合 DoT。

### 档位命中率一览（无 mech 纯技能）

| 怪类型 | 配置 chance | 实际施放概率 |
|---|---:|---:|
| 普通怪（魔兽/悍匪/塔·normal） | 0.15~0.22 | **15%~22%** |
| 精英怪（塔·elite / 周本·elite） | 0.15~0.22 | **23%~33%** |
| BOSS（突破 12 档） | 0.20~0.34 | **40%~68%** |
| 野外反派（魂殿/黑盟/魔炎谷） | 0.19~0.25 | **38%~50%** |
| 塔/周本 BOSS（kind 兜底技） | 0.28 | **56%** |

## §5 待你拍板（本轮只整理，未改任何概率）

如果确认"技能确实该更频繁"，可选方向（**均未执行**）：

1. **抬高 mech 二次判定**：把控制类机制 p 从 0.22~0.35 抬到 0.4~0.5 —— 最能改善"感觉没放技能"，但要防控制链过强。
2. **精英/BOSS 技能本体再提档**：×1.5/×2.0 提到 ×2/×2.5 —— 简单直接，但 BOSS 可能接近每回合放技能。
3. **改为每场保底触发 N 次**：首次攻击必放一次技能 —— 体验最稳定，但改动判定结构最大。
4. **不动概率，改播报**：技能未触发时也偶尔给"蓄势"提示 —— 零风险，纯观感。

我的建议：优先 1（机制 p 抬到 ~0.45），其次 3（BOSS 首回合保底一次），不建议动技能本体倍率（balance 风险最高）。等你拍板再改。
