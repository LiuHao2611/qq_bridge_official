# qq_bridge 常驻服务器 —— 硬件选型与采购清单

> 时间：2026-11-21
> 背景：小米6（sagit）刷机入口客观锁死（主线内核无 reboot reason + 用户按键故障 + Windows 缺签名驱动），用户拍板换机。
> 目标：24 小时稳定跑 qq_bridge_official + NapCat，局域网 + 外网访问，SSH 维护。

## 一、决定性事实：选 x86 可以零代码重构

这是本次选型最重要的判断：

- **qq_bridge_official 当前镜像是 amd64**（`docker images` 已确认），`docker-compose.official.yml` 已配好。
- **NapCat 官方镜像 `mlikiowa/napcat-docker` 同时提供 linux/amd64 和 linux/arm64**（2026 实测 v4.18.28/37 均含双架构）。
- 结论：**选 x86（Intel N100 迷你主机），现有两个镜像原样搬过去即可运行，重构成本 = 0。**
- 若选 ARM（树莓派/香橙派/OnePlus6），qq_bridge 必须做 arm64 重构 + 全量重测（项目记忆里明确写了"qb 现镜像 amd64，手机需 arm64 重构"），这是几十条守门测试的工作量。

**所以推荐 x86，不是因为它性能最强，而是因为它让"换机"这件事的工程量最小、见效最快、最稳。**

## 三、为什么小米6 走到换机（简要复盘）

- pmOS mainline 6.0 内核：modem 启动 `start timed out -110` 是 msm8998 主线社区未解难题（GitLab issue #15 悬至今天）。
- 6.11 的 MSA 修复只是 ath10k 的 3-commit 补丁，且现成 sagit 6.11 内核全论坛不存在（degradation fork 停 2021/5.11）。
- 主线内核缺 `msm-restart` 绑定 → 所有软件 `reboot(bootloader)` 无效 → 进不了 fastboot。
- Windows 无签名 fastboot 驱动 + 用户按键故障 → 物理路径也堵死。
- 详见 `手机服务器全系统横向裁决_2026-11-21.md`。

## 四、方案①推荐采购清单（N100）

### 必买
1. **N100 迷你主机整机**（不要准系统，省事）
   - 推荐配置：N100 / **16GB 内存** / 256GB 或 512GB NVMe / 双 2.5G 网口
   - 品牌参考：零刻 EQ12、铭凡 UN100C、步睿尔 BREN6M 等
   - 预算：**¥700-1300**（京东自营活动价，国补可更低）
   - ⚠️ 内存选 16GB 一步到位（板载/单通道不可升级）；8GB 也能跑但余量小
2. **备用：一台旧显示器或 HDMI 假负载**（无显示器也能 SSH，但首次装系统方便）

### 可选
3. UPS/智能插座：防突然断电（N100 有 NVMe，意外断电风险高于手机）
4. 网线：超五类及以上，接路由器 LAN 口

### 不推荐
- 准系统（需自己装内存硬盘系统，省的钱不够折腾）
- ARM 开发板（除非明确要 arm64 重构练手）
- 二手 OnePlus 6（社区仍 experimental，且要 arm64 重构，等于换个坑踩）

## 五、软件迁移路径（换机后，方案①）

因为零重构，迁移非常直接：

1. **装系统**：Ubuntu Server 24.04 LTS 或 Debian 12（x86_64），装 Docker Engine + Compose V2。
2. **搬镜像**：把现有的 `qq-bridge-official:latest`、`qq-doupo-agent:latest`、`mlikiowa/napcat-docker` 镜像 `docker save` → 传到新机 → `docker load`（或直接从源重新 build/pull）。
3. **搬数据**：`data/` 目录（SQLite 存档 + 配置）整体拷贝，注意保持权限和路径 `/app/data/...`。
4. **改 compose**：`MANJU_API_BASE` / `TASK_MONITOR_BASE` 里的 `host.docker.internal` 要改成新机实际可达地址；NapCat 的 OneBot 地址同理。
5. **外网访问**：Tailscale（私网，无需公网 IP，装一个包即可）或 Cloudflare Tunnel/frp。SSH 走 Tailscale 最省事。
6. **保活**：新机是真 Linux，无 Android 杀后台问题；配 systemd 开机自启 + `restart: unless-stopped` 即可。
7. **监控备份**：外部机器定时 ping + 服务健康检查；`data/` 定期备份。
